# Мика: набор старых фонов снят с использования

Все ранее отобранные изображения планет в этой ветке удалены из актуального дерева файлов по просьбе автора проекта. Отрисовка фонов будет производиться заново.

Подробные спецификации и каталог планет сохранены в основной ветке `main` и в документации исследовательской ветки `assets/mika-planet-source-images`.
