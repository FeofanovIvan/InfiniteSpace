# Как подключить Planet2D в проект Мико

1. Скопируйте папку `planet2d/` целиком в корень проекта Godot (`res://planet2d/`).
2. Откройте свой проект в Godot. В инспекторе или в дереве сцены добавьте экземпляр `res://planet2d/planet_2d.tscn`.
3. Поставьте его в нужные координаты `position`; масштаб задавайте через `diameter_pixels` или `set_planet_diameter()`.
4. Для запуска вращения ничего не нужно: он работает в `_process()` автоматически.
5. Для ночной стороны используйте `set_sun_direction(Vector3(...))`. Для переключения: `planet.paused = true`, `planet.set_clouds_enabled(false)`.
6. Для других планет назначьте другую **equirectangular** (2:1) карту поверхности в `surface_texture` или через `set_surface_map()`; для планет без огней поставьте `night_lights_enabled = false`, без облаков — `clouds_enabled = false`, без атмосферы — `atmosphere_strength = 0`.

ВНИМАНИЕ: `planet2d.gd` намеренно ссылается на `res://planet2d/...` — при иной структуре путей обновите соответствующие `preload()`.

В сцене игрового космоса используйте `z_index`/слои так, чтобы планета располагалась позади корабля Мико. Большое число крупных планет одновременно может нагружать мобильный GPU; разумно оптимизировать их размер, количество и отключать неиспользуемые ночные/облачные слои.

Объект не включает физическое столкновение, гравитацию, ночной цикл по астрономическому времени, реальные погодные данные и планетные кольца. Эти функции добавляются в игровой проект отдельно.
