# Баббл — действие 01: ПОКОЙ

**Роль:** исходное состояние между всеми действиями. Никакого перемещения, новой мимики или реквизита.

## Ритм / поза

| Составляющая | Приблизительный параметр | Как воспринимается |
|---|---|---|
| Основное дыхание | 4,2 секунды на цикл | Медленный вдох и выдох, без заметной «накачки» |
| Изменение радиуса | около 1,1% | Объём чуть увеличивается и уменьшается |
| Вертикальное смещение | около ±3 px в локальной системе | Плавная посадка и приподнимание |
| Покачивание корпуса | до ±0,7° | Впечатление упругого живого тела |
| Соседние пузыри | 2–5 px, с разными фазами | Не висят неподвижными, не расходятся |
| Реакция боковых пузырей | пружина с затуханием | Плавное запаздывание относительно ядра |
| Малый верхний пузырь | отдельно реагирует на вдох | Намёк на живой объём |
| Микроперераспределение | примерно раз в 16 секунд | Не возникает впечатления бесконечного повтора |

## Анимационный цикл

**0–1,8 с:** спокойное увеличение тела; боковые пузыри чуть расходятся в пределах связанного силуэта.

**1,8–4,2 с:** возврат к обычной форме; боковые пузыри постепенно догоняют центральный.

Периодический цикл — непрерывный, не ограниченный 4,2 секунды, отдельные медленные колебания идут в своём темпе и не синхронизируются искусственно.

## Что обязательно сохранить

- Основной круг легко читается.
- Отдельные пузыри остаются **связанными**, никаких отрывов на покое.
- Тело кажется упругим, но не пульсирует слишком сильно.
- Глаза и рот остаются ровно на своей лицевой поверхности.
- Покой может длиться бесконечно; лицо потом будет отдельно оживляться мимикой.

## Критерии приёмки

- Персонаж не движется по сцене.
- Ни один дополнительный пузырь не пересекает границу прямоугольника шейдера.
- Все циклы без резкого скачка на границе вдох/выдох.
- Регуляторы изменяют текущую сцену в реальном времени.
- После паузы всё продолжается без рывка.
- Годится как базовое состояние для переходов к ходьбе, еде, питью, купанию.
