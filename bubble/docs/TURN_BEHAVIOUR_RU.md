## Принципы
- Центральный пузырь визуально сохраняет сферическую форму.
- Сателлиты имеют координаты в воображаемом пространстве X/Z и проецируются в X экранной плоскости. Они не жёстко вращаются единым спрайтом.
- Пружинные соединения/запаздывание включены всегда; отдельно регулируется упругость.
- Нижние пузыри служат мягкими опорами, в повороте отрываются попеременно.
- Лицо с исходными PNG не получает новой мимики. При 90° оно исчезает за краем силуэта, при 180° показывается спина без лица.
- Для последующего игрового приложения механика поворота локальна персонажу, а перемещение по миру принадлежит контроллеру сцены.

Следующие стадии: согласование движения и внешнего вида, улучшение 2.5D-пропорций, затем другие группы действий. Эмоции отдельным этапом.
