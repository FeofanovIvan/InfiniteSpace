# Матрица действий и мимики Bubble

Идентификаторы используются в `bubble.play_action(id)`. Каждая анимация тела сохраняется в собственном исходном рендерере, а мимика создаётся слоем `ProceduralFaceRig` внутри `Body/Face` и подчиняется общему `MikaBubbleBrain`.

## Приоритеты выражений

- По умолчанию действие задаёт выражение. `set_expression(id)` может вручную его переопределить без изменения движения тела.
- Для критичных игровых действий `brush_teeth` и `gas` используется заранее спланированная мимика независимо от ручной эмоции, чтобы не блокировать игру.
- В `set_mouth_open()` можно временно управлять раскрытием челюсти в обычных состояниях. В `brush_teeth` приоритет у игровой челюсти.
- Обычные персонажные движения могут завершаться автоматически, а чистка зубов длится, пока не будет удалено не менее 92% налёта.

## Дальнейшее улучшение

Переходы эмоций сейчас реализованы заменой слоёв глаз/рта в нужные фазы и плавной анимацией челюсти; интерполяция геометрии бровей и век пока не реализована. Это следующая ступень качества после проверки графики на реальном устройстве.
