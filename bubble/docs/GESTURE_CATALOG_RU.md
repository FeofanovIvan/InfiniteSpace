# Каталог анимаций жестов Баббла

| ID | Русское название | Длина | Основная кинематика |
| --- | --- | ---: | --- |
| `wave` | Махание | 2.65 с | Боковой пузырь поднимается, повторяет 3 взмаха; мембрана между ним и центром удлиняется. |
| `jump` | Прыжок | 1.62 с | Накопление упругости → полёт до 168 px → приземление → восстановление. |
| `roll` | Перекат | 2.38 с | Сомершальт по плоскости (360°) с перемещением по полу, лицевая панель крутится с туловищем. |
| `float` | Парение | 3.50 с | Мягкий набор высоты до 120 px, дрейф, опускание; незаземлённые вторичные пузыри. |
| `spin` | Вращение | 2.45 с | Вращение вокруг вертикальной оси, 2.5D, временный вид со спины. |
| `look` | Оглядывание | 3.10 с | Осмотр влево, вправо и вверх, поворачивается корпус и смещается область лица. |

## Разделение ответственности

- Процедурное тело: `scripts/bubble_gesture.gd` + `shaders/bubble_metaball.gdshader`.
- Отдельные PNG слои глаз и рта: `assets/face/`.
- Сам объект: `scenes/bubble_gesture.tscn`, с методами `start_gesture(id)` и `advance(delta)`.
- Перемещение относительно сцены: `motion_offset` (пиксели до масштабирования), контроллер тестового экрана применяет его к положению инстанса.
- Высота над землёй: `lift_height` для тени; маркеры только тестовые.
- Межпузырчатая инерция: отдельная пружина для каждого сателлита, параметр `spring_responsiveness`.

## Важно

1. `roll` — визуальное вращение в плоскости экрана, `spin` — объёмный разворот вокруг вертикальной оси. Это разные жесты.
2. `look` — пока перемещение **всей** группы элементов лица, а не изменение мимики или направления зрачков; отдельные PNG-эмоции позже.
3. `float` — визуальное парение, не физика в вакууме.
4. Фон и тени технические, позже подменить на космос из Infinity Space.
5. Этот проект изолирован; не перезаписывает основной проект и не меняет Godot.
