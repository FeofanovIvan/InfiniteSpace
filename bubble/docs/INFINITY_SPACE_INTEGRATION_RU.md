# Подключение к основному Infinity Space

**Важно:** самостоятельный проект не изменяет установленный `InfiniteSpace_Godot`. Для интеграции нужно сперва протестировать все группы, затем подключить отдельный пакет сцен и ресурсов к рабочей ветке основного проекта. Не перезаписывать уже существующие файлы с совпадающими именами без проверки.

1. Сохранить резервную копию `InfiniteSpace_Godot`.
2. Перенести папки `scripts`, `scenes`, `shaders`, `assets/face` и `docs/expression_presets.json` в обособленный модуль `res://bubble/`. **После переноса потребуется изменить пути `res://...` в сценах и скриптах на `res://bubble/...`.** Альтернативно перенести проект в отдельную ветку и обеспечить уникальные пути.
3. Создать один экземпляр `bubble_character.tscn` в сцене ухода/каюты.
4. Вызывать действия через `MikaBubbleBrain.play_action` и слушать сигналы `action_started`, `action_finished`, `brush_ready`, `brush_progress_changed`.
5. Механику щётки привязать к конкретным координатам игрового экрана вызовом `bubble.brush_teeth_at(global_point, radius)`. Обработчик ввода находится в тестовой сцене `unified_lab.gd` и показан как пример.
6. Оставить Godot 4.7.1. Не устанавливать другие версии движка.

Пока это интеграционная демонстрация, а не автоматически применённый патч к основному проекту.
