# InfiniteSpace v54 — Barnard's Galaxy fleet + туманности для всех внешних систем

Что добавлено:

- Для **Barnard's Galaxy / NGC 6822** вырезан исходный флот пользователя без генерации новых изображений.
- Добавлены 5 чистых PNG-кораблей:
  - `ngc6822_cargo_01.png` — Heavy Cargo Hauler
  - `ngc6822_interceptor_02.png` — Needle Interceptor
  - `ngc6822_patrol_03.png` — Frontier Patrol Ship
  - `ngc6822_liner_04.png` — Garden Passenger Liner
  - `ngc6822_merchant_05.png` — Trade Ring Vessel
- Проверена ориентация грузового корабля: его нос направлен вниз (+Y); полёт и гиперпрыжок соответствуют этому направлению.
- В `ForeignTraffic.gd` регион `ngc6822` включён в native fleet с той же логикой подлёта, посадки, взлёта и прыжка носом, что уже используется у других родных флотов.
- Во **всех шести системах** (`mw`, `lmc`, `smc`, `ngc6822`, `m31`, `m33`) добавлены общесистемные туманности на заднем плане. Они:
  - рисуются **за планетами и станциями**;
  - используют тот же шейдер газовых облаков, который уже применялся в игре;
  - распределяются по всей системе, а не только около одной станции.
- Для этого поднят порядок отрисовки: звезда `z=2`, планеты и сюжетная станция `z=3`, фоновые туманности `z=1`.
- Перекрёсток миров полностью сохраняет **36** более насыщенных газовых сгустков из v53 (не заменяется устаревшей версией).
