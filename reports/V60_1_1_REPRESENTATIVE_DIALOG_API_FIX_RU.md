# InfiniteSpace v60.1.1 — исправление падения диалога с представителем

Источник: `release/v60_1-installed-snapshot`, `planet_hub/scripts/representative_dialog.gd` SHA-256 `813bc72dbc875b64688651afcaf59f521911b27aad31a1e7e6940886c20bac42`.

Ошибка при открытии представителя: `Invalid call. Nonexistent function 'raise' in base 'Button'` (строка 73).

Исправления: `_back_button.raise()` → `_back_button.move_to_front()` (совместимый API Godot 4). Неиспользуемый аргумент `planet_name` → `_planet_name`. Эти две строки — единственные изменения игрового скрипта.

Сохраняется: отсутствие стартового опросника; заранее записанные ответы Алися/3/голубой; шесть локалей и оба написания имени; полноэкранный двухпанельный диалог; возвращение на планету; все остальные игровые подсистемы.

Безопасная установка: проверить исходный хеш, ZIP SHA256, сделать backup одной копии изменяемого файла, атомарно записать новый, выполнить статическую проверку и автоматически откатить на ошибке. Поддерживается повторная установка. Синхронизация полного проекта выполняется после успешной локальной установки, в ветку `release/v60_1_1-installed-snapshot`.

Godot 4.7.1 runtime и нажатие F5 в этой среде проверить невозможно: финальная проверка на Mac обязательна.
