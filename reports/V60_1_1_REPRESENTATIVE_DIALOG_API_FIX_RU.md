# InfiniteSpace v60.1.1 — исправление падения экрана представителя в Godot 4

**Версия основы:** `release/v60_1-installed-snapshot`.

## Отчёт об ошибке

Вызов `representative_dialog.gd:73` из `_layout_ui()`:

```
Invalid call. Nonexistent function 'raise' in base 'Button'
```

`CanvasItem.raise()` — метод Godot 3, в Godot 4 он называется `CanvasItem.move_to_front()`.

## Точные изменения

- `_back_button.raise()` → `_back_button.move_to_front()`
- Неиспользуемый параметр `planet_name` → `_planet_name` в сигнатуре `configure_for_planet()`.

В файле `planet_hub/scripts/representative_dialog.gd` изменены **только две строки**. Никакая логика диалога, пользовательский профиль, шесть языков, кнопки, обучение и стартовый экран не меняются.

## Установка и проверки

Патч `InfiniteSpace_v60_1_1_Hotfix_RepresentativeDialog_Godot4.zip` с SHA-256 `501300ae5d018351db8f5c081664e09da4fcb206b706518ae99b0962aa982f32`.

Установщик использует контрольную сумму опубликованного v60.1, делает резервную копию скрипта, атомарную запись и откат при ошибке. Повторная установка — без повторной записи. Тесты: первичная установка PASS, повторная PASS, отказ от неизвестной пользовательской версии PASS, отказ от повреждённого ZIP PASS, rollback при ошибке проверок PASS. Проводился статический поиск других методов `raise()` в скриптах планетного диалога — не обнаружено.

Полный снимок установленного проекта публикуется из Mac в ветку `release/v60_1_1-installed-snapshot` (при доступном git и git-lfs). После установки открывается редактор Godot 4.7.1.

**Ограничение:** фактический запуск движка Godot 4.7.1 через F5 не выполнен в среде сборки; нужен тест на Mac.
