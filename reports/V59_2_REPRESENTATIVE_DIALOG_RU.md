# InfiniteSpace v59.2 — дополнение к планетному экрану: представитель и переводчик

Основа: полный установленный снимок `release/v59_1-installed-snapshot`. Источник дизайна и игровых сцен: предоставленный пользователем `Mika_Planet_Hub_Godot4_dialog_v2.zip`.

Обитаемые планеты: нажатием на карточку представителя открывается полноэкранный диалог, не покидая основную сцену Godot. Слева портрет или исходная Godot-голограмма, рядом отдельная подсказка, справа интерактивный переводчик с историей сообщений, клавиатурой, кнопками «Заново» / «Отправить». Упражнение: P R I V E T → «Привет», ответ и перевод. Озвучивание пока только placeholder. Кнопка «Назад» и Esc возвращают на **ту же планету**, сохраняют корабль и ресурс топлива.

Необитаемые планеты: карточка представителя скрыта, задание и нижний HUD доступны без изменений. Фон и портрет могут позднее загружаться по ID из `planet_hub/backgrounds/<planet_id>.png` и `planet_hub/cards/<planet_id>_representative_dialog.png`.

В ZIP внесены текстовые сцены и скрипты исходного архива, адаптированные пути `res://planet_hub`, безопасные подключения в `Main.gd` и `planet_hub_overlay.gd`, статический тест, транзакционный установщик, Mac shell + GitHub sync. Самостоятельный архив-пример не заменяет основной Godot-проект.

SHA-256: `ff9cb8b6f507c179667f1b298f18f1d2167cec5af9fa9b13305280a8ac104655`.

**Важное разделение:** исходная ветка `release/v59_2-representative-dialog` хранит ключевые кодовые изменения и отчёт, а полный набор скриптов диалога устанавливается из ZIP; полный локальный проект, включая остальные игровые ресурсы, отправляется установщиком Mac в `release/v59_2-installed-snapshot` (если Git LFS и доступ к GitHub работают).
