# InfiniteSpace v73 — эталонные фоны LMC/SMC, очищенные персонажи, отступ формы жизни

Основа: установленная локальная v72. **Полный игровой патч поставляется ZIP-архивом**, эта ветка — только паспорт версии, чтобы не перезаписать локальную сборку Mac старыми файлами репозитория.

- ZIP: `InfiniteSpace_v73_FixedWorlds_CleanCharacters_Icon.zip`, SHA-256 `ed04ff6357e5121325b55e796632bb46e8110b4873b26bf3901f5c2e9426e101`, 43 953 991 байт.
- **15 действующих PNG персонажей**: последние 12 отдельно предоставленных картинок побайтно совпадают с чистыми `infinity_space_cutouts_clean_v6.zip`; ещё 3 недостающих действующих PNG (10,15,18) взяты из того же архива. `11_phase_gas(1).png` установлена под каноническим `11_phase_gas.png`. Не назначать персонажей 03/04, исключённых из диалогов.
- **LMC 9 фонов:** Аэра `lmc_p01`, Талас `lmc_p02`, Молия `lmc_p03`, Криона `lmc_p04`, Карбона `lmc_p05`, Люкс `lmc_p06`, Вентра `lmc_p07`, Магнета `lmc_p08`, Тарантул `st_lmc`. Источник — `большое облако(3).zip`; декодирование имен из ZIP с CP437→UTF-8 и Unicode NFC, точное совпадение имени, **никаких перестановок Молии и Вентры**.
- **SMC 9 фонов:** Окея `smc_p01`, Цела `smc_p02`, Генора `smc_p03`, Мицела `smc_p04`, Спира `smc_p05`, Амбра `smc_p06`, Силика `smc_p07`, Биора `smc_p08`, Живой архив `st_smc`. Источник `Малое облако(2).zip`.
- **HUD:** отступ между первой вертикальной разделительной чертой и левым краем центральной иконки жизни увеличен ровно на 20%, при этом и иконка, и текст сдвинуты на одинаковую величину, сохраняя их взаимный зазор. Замена работает только при SHA v72; если локальный HUD отличается, скрипт пропускает его, не блокируя обновление графики.
- **Защита:** все записываемые файлы предварительно проверены по SHA256 из manifest; защищены пути и symlinks; перед заменой создаётся резервная копия; установки атомарны, с откатом при ошибке; повторная установка безопасна.
- **Не затрагивается:** `Main.gd`, `atlas/world_atlas.json`, `representatives.json`, миссии, нижний HUD. Назначение планеты ↔ персонаж остаётся прежним.
- **Тесты:** ZIP CRC PASS, 34 хеша ассетов PASS, запись/backup PASS, повторный запуск PASS, неизвестный HUD пропускается PASS, защита от symlink PASS, проверка математики +20% PASS. Godot GUI на Mac запустит установщик после установки; прямой F5 тест на Mac здесь не выполнялся.

Команда:

```bash
PROJECT="$HOME/Projects/InfiniteSpace/InfiniteSpace_Godot"
ZIP="$HOME/Downloads/InfiniteSpace_v73_FixedWorlds_CleanCharacters_Icon.zip"
unzip -tq "$ZIP" && unzip -p "$ZIP" install_and_launch_v73.sh | bash -s -- "$PROJECT" "$ZIP"
```

После установки обязательно визуально проверить старые/новые изображения в интерфейсе и соответствие атмосферы утверждённым описаниям. Название PNG подтверждает привязку к ID, но само по себе не гарантирует художественного соответствия описанию.
