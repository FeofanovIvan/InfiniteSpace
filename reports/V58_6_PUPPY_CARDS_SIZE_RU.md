# InfiniteSpace v58.6 — размер собаки и карточек

Базовая версия — установленная v58.5 (исходный `scripts/MikoMainMenu.gd` с Git blob `23ea87ee560ccacd7b77978567b72f6e41b7be18`).

Изменения исключительно в экране корабля:

- **Собака:** видимый размер ровно ×3 относительно v58.5 (`0.26` → `0.78` при том же масштабе устройства). Точки опоры подняты, чтобы собака не обрезалась снизу; боковые пределы бега также сдвинуты внутрь на половину новой ширины.
- **Область нажатия:** увеличена в три раза вместе с собакой, сохраняет открытие оригинального игрового ухода `pet_home_miko.tscn`.
- **Все образовательные карточки:** обе стороны умножены на `0.85` после прежних ограничений по размеру, поэтому нет искажения пропорций и реальное уменьшение составляет 15% в любом поддерживаемом landscape-экране.
- **Не меняются:** оригинальные анимации, бег, пять действий ухода, награды, горизонтальный swipe, изображения, корабли и станции.

Содержимое: только обновлённый GDScript, проверка и отчёт. Установщик делает резервную копию, проверяет исходник v58.5 по хешу и повторную установку, запускает Godot и пробует синхронизировать полный проект в GitHub `release/v58_6-installed-snapshot`.

Реальное графическое исполнение Godot F5 должно быть проверено на Mac.
