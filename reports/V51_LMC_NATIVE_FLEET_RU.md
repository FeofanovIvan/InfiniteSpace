# InfiniteSpace v51 — исконный флот Большого Магелланова Облака

Исходный лист: `Alien Biomechanical Starship Showcase.png`, 1536×1024 RGBA. Никаких новых изображений не генерировалось.

| Расположение | Файл | Класс | Поведение |
|---|---|---|---|
| Слева сверху | `lmc_merchant_01.png` | Торговый | Обитаемые торговые маршруты, средняя скорость и стоянки |
| Справа сверху | `lmc_shuttle_02.png` | Гражданский пассажирский | Регулярное сообщение, короткие стоянки |
| По центру | `lmc_freighter_03.png` | Тяжёлый грузовой | Медленный, длинные стоянки на планетах и станции |
| Слева снизу | `lmc_explorer_04.png` | Разведывательный | Быстрый, дальние рейсы |
| Справа снизу | `lmc_escort_05.png` | Патрульный / охрана | Патрули по соседним портам |

В Большом Магеллановом Облаке создаются семь NPC пяти классов: два начинаются на посадке, два заходят на неё, остальные находятся на маршрутах. Корабли используют уже существующий `ForeignTraffic.gd` (посадка, стоянка, взлёт, полёт и гиперпрыжок с направлением строго по носу); не создаются в SMC, M33 и остальных системах.

NPC выбирают только обитаемые планеты и единственную станцию из `atlas/world_atlas.json`. Прочие планеты не становятся местами посадки.

Изображения извлечены Python из пользовательского листа по альфа-каналу с аккуратной обработкой края; исходная графика корпуса не дорисовывалась. PNG и ведомость контрольных сумм в составе патча.

Проверки: целостность PNG и архива, статические инварианты, идемпотентность установщика. Проверка движения через F5 остаётся необходимой на Mac.
