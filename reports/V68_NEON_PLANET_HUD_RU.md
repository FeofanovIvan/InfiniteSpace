# InfiniteSpace v68 — неоновая нижняя панель планет

База фиксации: `release/v67_1-v65-compatible-landings`. Поставка — автономный Mac ZIP патч (это не полный Godot snapshot). Репозиторий `main` не изменялся.

**Дизайн по скриншоту пользователя:** слева голубая вытянутая капсула «Симулятор» с круглой эмблемой астронавта; по центру насыщенно-синяя капсула с кристаллом, светящейся вертикальной чертой и живым счётчиком; справа янтарная капсула «Запуск» с круглой эмблемой корабля. Эмблемы и кристалл вырезаны из предоставленного изображения; капсульные панели созданы отдельно с прозрачным фоном и девятипатчевым масштабированием. Сигналы интерфейса и 6 языков сохранены.

Локально заменяется **только** `planet_hub/scripts/bottom_hud.gd`; добавляются **6** PNG в `planet_hub/assets/v68_neon/`. Не затрагиваются `Main.gd`, атлас, фоны планет, миссии и представители.

ZIP: `InfiniteSpace_v68_Patch_NeonPlanetButtons.zip`, SHA-256 `2e9c120b30281c0b19ba9f0baa8f0afa2ba6ae358487531b56955becdf1658bd` (315107 байт). Готовый Godot HUD Git blob: `8bd58478869c624d4791339a69fc0019546140fe`.

Проверяется исходный HUD по известным Git blob v63/v64(v65)/v66, создаётся резервная копия, обновления атомарные с откатом. Повторная установка безопасна. **Пять тестов PASS**: манифест+арт, установка+повтор, отказ при конфликте скрипта, отказ при конфликте ресурса, адаптивная геометрия. ZIP integrity PASS. Запуск Godot 4.7.1/F5 **не проверен** в Linux-сборке (нет Godot).

Установка Mac: `unzip -tq "$ZIP" && unzip -p "$ZIP" install_and_launch_v68.sh | bash -s -- "$PROJECT" "$ZIP"`. После успешной установки запускаются Godot Editor и отдельное окно игры, если Godot найден на Mac.

**Внимание:** в этой ветке — документ-паспорт патча; бинарные новые PNG и итоговый GDScript доставляются ZIP-архивом. Установленная Mac-версия пока не опубликована в GitHub как полный snapshot. Не брать старый HUD из этой ветки поверх локального v68.
