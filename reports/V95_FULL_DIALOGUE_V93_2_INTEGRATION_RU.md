# InfiniteSpace v95 — полная интеграция диалога MIKA v93.2

**Исходный ZIP пользователя**: `MIKA_representative_cloud_dialog_v93_2 (1).zip`. Создан самодостаточный **Mac-патч** `InfiniteSpace_v95_Full_New_Dialog_Integrated.zip` (59 420 байт; SHA-256 `c641191748b6936093e91c1bec89ce674016988ba5fe2d655eafe6dd137e7883`).

**Пользователь потребовал** *полностью заменить старый диалог на новую механику*, а не ограничиться визуальными облаками или сохранить старую фиксированную анкету.

## Что перенесено

Полная сцена через существующий `representative_dialog.tscn` использует новые `planet_hub/scripts/representative_dialog.gd`, `translator_tablet.gd`, `child_profile_store.gd`, новые `dialogue_engine.gd`, `dialogue_input_matcher.gd`, `cloud_choice_button.gd`, `planet_hub/data/dialogue_worlds.json`, `planet_hub/data/dialogue_phrases.json` и тестовые сцены/скрипты.

- Левая половина: три плавающих облачных подсказки **над персонажем**. Выбор не отправляет сообщение — требуется самостоятельный ввод; распознаватель принимает правильное намерение независимо от выбранного облака.
- Правая половина: чат + экранная клавиатура на шести языках, язык из общих настроек `MobileLocale`.
- 10 разговорных тем, отдельные сведения 48 планет + 6 станций (30 обитаемых объектов с представителями), математические примеры, отслеживание посещений/ранее заданных тем в `user://miko_dialogue_progress.json`, добровольно названные имя/возраст/цвет в `user://miko_child_profile.json`.
- Регистр/пробелы/пунктуация и небольшие ошибки: Damerau-подобная строковая дистанция с консервативным лимитом от 0 до 3 правок, запрет ошибки в числах и изменения наличия отрицаний.
- Устранена ошибка сохранения личных значений с отрицанием («не люблю синий», «мне не семь»), возраст берётся из первого допустимого цифрового токена, а не наименьшего в предложении.
- Сохранено живое `MagneticLiquid.tscn` v93 **только при диалоге** в четырёх объектах M31 (Фазис/Синта/Геона/Перевёрнутая пирамида), оригинальные байты трёх magnetic files из предоставленного архива.
- Автоматически подхватывается портрет представителя из текущего `planet_hub/data/representatives.json`, если старый диалог передаёт пустую картинку.

Не заменяются `Main.gd`, `project.godot`, `MobileLocale.gd`, `representative_dialog.tscn`, `dialog_character.gd`, реестр представителей, оригинальные карточки, мини-игры и фон.

## Готовность и ограничения

**Достаточно для первого живого тестирования**, не окончательный универсальный диалоговый ИИ. Это полностью офлайновый намеренческий движок, знает синонимы лишь из массива заранее записанных формулировок. Параметры и факты рас/планет существуют в RU/EN; UI и три фразы на FR/DE/ES/PT_BR поддержаны, но содержательные реплики могут быть на English. Нет речевого ввода, нет произвольного «понимания смысла» естественного языка и нет бортового LLM.

Включены исходные `dialogue_smoke.gd`, `representative_dialog_ui_smoke.gd`, `dialogue_typing_tolerance_smoke.gd` + 4 проверки отрицаний/числовых возрастов. На сборочной машине не было Godot, поэтому **реального Godot 4.7.1 headless/run нельзя считать проверенным**. Выполнены: Python compile, Bash syntax, ZIP CRC и SHA PASS; mock installation, repeat no-op, backup, rollback, conflict fail-safe PASS; данные 54 worlds, 30 assigned/inhabited, 10*6*3 phrases verified.

## Установка Mac
```bash
PROJECT="$HOME/Projects/InfiniteSpace/InfiniteSpace_Godot"
ZIP="$HOME/Downloads/InfiniteSpace_v95_Full_New_Dialog_Integrated.zip"
unzip -tq "$ZIP" && unzip -p "$ZIP" install_and_launch_v95.sh | bash -s -- "$PROJECT" "$ZIP"
```
Только Godot 4.7.1, резервная копия `InfiniteSpace_backup_before_v95_*` рядом с Mac-проектом; откат из ZIP `rollback_and_launch_v95.sh`. Текущие модифицированные три GDScript заменяются по прямому явному запросу пользователя; новый/неизвестный ресурс с другими байтами вызывает отказ.

**Ветка хранит паспорт ZIP**, не снимок установленного у пользователя Mac-проекта.
