# Отчёты Infinite Space

Это постоянная папка `InfiniteSpace_Godot/reports/`, предназначенная для ZIP-пакетов диагностики, которые можно отправить в чат для анализа.

## Что фиксируется автоматически

При каждом запуске Godot сценарий `scripts/Diagnostics.gd` создаёт **новый** журнал JSONL в `user://reports/` (системная пользовательская папка Godot, на Android также доступна приложению):
- версия Godot, операционная система и размеры окна;
- контрольные записи о работе мини-карты;
- каждые 25 секунд — сектор корабля, положение внутри сектора, скорость и FPS;
- нажатия кнопки действия, перетаскивание карты и возвращение к кораблю;
- завершение запущенной сцены, если Godot успевает корректно закрыть её.

Сохраняются только сведения о прототипе, а не персональная информация. Один запуск — один файл; предыдущие отчёты не удаляются.

## Как создать ZIP после ошибки (Mac)

1. Запустить игру хотя бы один раз.
2. При неполадке **не очищать** пользовательские данные Godot.
3. Дважды щёлкнуть `tools/collect_reports.command` (или запустить его через `bash tools/collect_reports.command` из проекта).
4. Отправить полученный `reports/InfiniteSpace_Report_YYYY...zip` в чат.

Сборщик копирует журналы `user://reports` и обычные `user://logs` (если имеются) в отдельный ZIP. Не изменяет данные игры. Godot может не успеть записать ошибку, которая немедленно завершила процесс; в таком случае приложить снимок экрана и описание действий.

## Если отчёт не появился

На Mac Godot хранит файлы проекта примерно здесь:
`~/Library/Application Support/Godot/app_userdata/Infinite Space - Distant Stars/`

Расположение может отличаться из-за пользовательских настроек `user://`. Коллектор проверяет стандартные пути. В любом случае через меню Godot можно открыть `Project > Open User Data Folder`, затем `reports`.
