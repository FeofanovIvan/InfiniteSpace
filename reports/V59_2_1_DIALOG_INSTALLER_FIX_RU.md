# InfiniteSpace v59.2.1 — безопасное исправление установщика диалога

**Исходный архив v59.2 не установился.** Он ожидал строго один Git blob `scripts/Main.gd`: `09ce74371f4dfd609b7162908eab562ba5aaf4b1` из `release/v59_1-installed-snapshot`. Пользователь сообщил фактический локальный Git blob `5209543d154009e8efbe258e6abfe060efcf870f`.

Принцип исправления: **не** разрешать неизвестный hash и не заменять файл целиком. Вместо этого установщик `install_v59_2_1.py` проверяет уникальные участки кода посадки и добавляет исключительно обработчики диалога представителя. Он сохраняет все не относящиеся к ним локальные изменения. Если эти участки несовместимы с ожидаемым v59.1, установка безопасно прекращается без записи.

Скрипт обрабатывает `planet_hub_overlay.gd` аналогично — минимально изменяет только переход из карточки представителя. Прочие семь файлов по-прежнему проверяются по SHA-256. При успехе: backup изменённых файлов, атомарная запись, статические проверки v59.1/v59.2, rollback на ошибке, idempotent повторная установка, синхронизация полного проекта в `release/v59_2_1-installed-snapshot`, автоматический запуск Godot 4.7.1.
