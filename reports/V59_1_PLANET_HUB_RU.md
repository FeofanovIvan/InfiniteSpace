# InfiniteSpace v59.1 — исправленная интеграция общего экрана планет

База: release/v58_6-installed-snapshot; Git blob оригинального scripts/Main.gd:
`5b863c16f91cca740edc2e6e757c2d30734c7a8c`.

Исправлено по сравнению с нерабочей выдачей v59:
- известный путь пользователя: `$HOME/Projects/InfiniteSpace/InfiniteSpace_Godot`;
- настоящий ZIP и штатный one-paste установщик Mac;
- полный безопасный backup изменённого Main.gd с откатом при неудачной проверке;
- экран вставлен в штатный CanvasLayer/HUD, а не поверх Node2D позади интерфейса;
- задействуется действующий обработчик посадки после проверки расстояния;
- посадка разрешена для всех планет с `landing=landing`, включая необитаемые;
- представители показываются только при `inhabited=true`, задания доступны остальным;
- станционные посадки остаются в LandingPreview;
- существующие меню Play Town, добыча топлива и NPC не изменены;
- `Main.gd` изменён лишь в точках входа/выхода планеты и выбора кнопок;
- начальная сюжетная посадка на Землю открывает тот же экран;
- нижние кнопки «Симулятор» и «Вылет» получили исходные PNG пользователя;
- разные фоны подключаются позднее по planet_id (не используем готовый скрин с запечёнными кнопками);
- синхронизация полного снимка в `release/v59_1-installed-snapshot` при успешной авторизации GitHub и git-lfs.

Проверка: статическая структура, контрольные суммы ZIP, транзакционная тестовая установка,
повторная установка и отказ при неизвестной правке. Запуск Godot F5 на Mac требуется отдельно.
