# InfiniteSpace v59.1 — исправленный экран планеты

База: release/v58_6-installed-snapshot, Main.gd Git blob 5b863c16f91cca740edc2e6e757c2d30734c7a8c.

Исправляет прежний v59: установка в $HOME/Projects/InfiniteSpace/InfiniteSpace_Godot, ZIP с полноценным установщиком, backup и проверками, запуск Godot 4.7.1. Экран добавляется в существующий CanvasLayer/HUD и использует обработчик посадки Main.gd. Отправляет на единый планетный экран после исчезновения корабля, включая сюжетное прибытие на Землю.

Для всех планет с landing=landing, независимо от обитаемости, доступна посадка. Карточка представителя есть только при inhabited=true; карточка задания есть всегда. Станции по-прежнему используют LandingPreview. Нижний HUD единый: шлем «Симулятор», баланс топлива-кристаллов и кнопка «Вылет» с заменённым значком корабля. Существующий симулятор Play Town не переписывается: после закрытия возвращается планетный экран. Фоны затем добавляются по ID планеты.

Архив: InfiniteSpace_v59_1_Patch_PlanetLandingHub_Fixed.zip
SHA-256: 4d2695247f62ee8063c5e1d4f0df7118ba2ebe658303d89eaa11ef4050ecac0b

Установщик проверяет исходный Git blob и SHA256 каждого ZIP-вложения, делает backup и транзакционно откатывает изменения при ошибке. Проверки на точной реконструированной v58.6: установка PASS, повторная установка PASS, отказ от неизвестной локальной правки PASS; проверены 35 landable planets, из них 24 inhabited (по текущему атласу). Реальный Godot runtime F5 в этой среде не проверен.

После установки sync_v59_1_to_github.sh пытается опубликовать полный проект и картинки в release/v59_1-installed-snapshot.
