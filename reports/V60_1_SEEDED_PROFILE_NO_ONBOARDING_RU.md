# InfiniteSpace v60.1 — предварительные ответы без стартового опросника

На старте игры НЕ показывается никакая форма знакомства, экран вопросов, модальное окно или блокировка пролога. Существующий autoload `ChildProfileStore` немедленно создаёт локальные тестовые данные и передаёт управление игре.

Тестовый профиль: имя **Алися** на кириллице; **Alisya** на латинице; возраст **3**; любимый цвет **голубой**. Русский чат показывает имя на кириллице, английский, французский, немецкий, испанский и бразильский португальский — на латинице. В любом языке ввод обоих вариантов имени принимается. Имя не «переводится» — сохраняются два написания.

Три вопроса по-прежнему лежат в `res://data/child_profile_seed.json`, чтобы позже реализовать отдельную регистрацию и логику знакомства. При первом запуске профиль автоматически записывается в `user://miko_child_profile.json` без взаимодействия с ребёнком. Уже существующая сохранённая анкета не стирается; её заполненные ответы сохраняются.

Чат с представителями планет по-прежнему работает. Клавиатура на шести языках, сообщения «печатает…», подсветка букв, ответы «Я тебя не понимаю. Повтори.», правый полноэкранный планшет и возврат на планету остаются.

Патч изменяет только `child_profile_store.gd`, `translator_tablet.gd`, `child_profile_seed.json`, `tools/check_v60.py`, добавляет `tools/check_v60_1.py`, этот отчёт, не меняя `Main.gd`, `project.godot` или игровой HUD.

Для установки: `InfiniteSpace_v60_1_Patch_SeededProfile_NoOnboarding.zip`. Установщик проверяет контрольные суммы файлов предыдущей установленной версии v60, делает backup изменяемых файлов, транзакционно устанавливает патч, откатывает при проверочной ошибке и открывает Godot 4.7.1 после успешной установки. Отдельная синхронизация GitHub в `release/v60_1-installed-snapshot`.

Runtime F5 и мобильный UI в текущем окружении проверить невозможно — требуется открыть проект в Godot на Mac.
