# V34 Callisto shipyard + spacing patch

## Что изменено
1. **Орбитальная верфь Каллисто**
   - текущая станция заменена на предоставленный арт `assets/story/callisto_shipyard.png`
   - верфь теперь крутится как отдельный орбитальный объект
   - позиция привязана к Каллисто через смещение `CALLISTO_SHIPYARD_OFFSET`

2. **Увеличены расстояния между звёздами и планетами в других системах**
   - в `OtherSystem.gd` добавено визуальное расширение орбит (`VISUAL_INNER_ORBIT`, `VISUAL_ORBIT_SCALE`)
   - мини-карта использует те же увеличенные орбиты

3. **Луны больше не режут орбитальные кольца/опоясывающие картинки**
   - лунам возле планет с орбитальными кольцами добавлен дополнительный радиус
   - повышен `z_index` у таких лун
   - в Млечном Пути также увеличены радиусы части лун, а земная Луна вынесена чуть дальше

4. **Ограничен свободный вылет за пределы системы**
   - корабль больше не уходит в бесконечность при обычном полёте
   - реальные мировые координаты ограничиваются радиусом системы
   - при этом звёздный фон продолжает двигаться, создавая визуальное ощущение полёта

## Изменённые файлы
- `scripts/AtlasSystem.gd`
- `scripts/OtherSystem.gd`
- `scripts/SolarSystem.gd`

## Проверка
Запуск статической проверки:
```bash
python tools/check_v34.py
```

## Важно
Это статическая проверка. В Godot всё равно нужно визуально открыть проект и проверить:
- размер верфи Каллисто
- не слишком ли далеко вынесены луны
- комфортность нового ограничения свободного полёта
