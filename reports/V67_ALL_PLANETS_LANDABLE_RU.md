# InfiniteSpace v67 — посадка на все планеты

Основа: `release/v66-installed-snapshot`. Изменения находятся в `release/v67-all-planets-landable`, основную ветку `main` не трогаем.

- Атлас: **48 из 48** планет имеют `landing: landing` и новый независимый флаг `landable: true`; исправлены 13 прежних `orbit`.
- **24 обитаемые** планеты остаются прежними. Необитаемые теперь доступны для ручной посадки, но не попадают в список автопилота (список намеренно фильтруется по `inhabited`).
- Автопосадка использует `landable` отдельно от `inhabited` и заданий. Станции остаются доступными и обрабатываются отдельно.
- `planet_hub/data/missions.json` без изменений: карточка появляется только при `enabled: true` для указанного ID, независимо от обитаемости.
- Карточка представителя по-прежнему только при `inhabited: true`; журнал посадок больше не помечает все миры обитаемыми.
- Все объекты системы Перекрёсток миров не являются элементами 48-планетного атласа, не менялись.

Установка на Mac — через отдельный ZIP-патч с резервной копией, проверкой SHA и повторяемостью. Запуск F5 в Godot на Mac нужно проверить после установки.

ZIP: `InfiniteSpace_v67_Patch_AllPlanetsLanding.zip`; SHA-256 `da06fc30db482810eae57f0fb7def5414d56ac14b13ad5fd44c7f37674967b66` (7722 bytes).
Тесты: пять проверок PASS — преобразование реестра, неизменность населения и станций, точные правки GDScript, установка, повторная установка, отказ при локальном конфликте, Git blob SHA. Реальный запуск Godot не выполнялся.
