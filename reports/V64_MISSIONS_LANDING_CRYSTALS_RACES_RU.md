# InfiniteSpace v64 — миссии, жесты, автопосадка, кристаллы и представители

База: `release/v63-installed-snapshot`. Архив: `InfiniteSpace_v64_Patch_Missions_AutoLanding_Crystals_Races.zip`.
SHA-256 ZIP: `ca6077a82cd0155ce07acefbf6736e01c6a140977451afb626ba27f53b2d81e6`.

1. **Задания:** новая БД `planet_hub/data/missions.json` изначально пустая. Карточка появляется **только** для существующего ID планеты или станции с `enabled: true`. Локализованные заголовок и описание берутся из самой записи, не из прежнего `unique` атласа. Дальше пополняем по отдельности.
2. **Прокрутка:** планетные карточки и верхнее меню используют `SCROLL_MODE_SHOW_NEVER`: нет полосы прокрутки, остаются touch-свайпы, добавлено перетаскивание мышью.
3. **Автопосадка:** выбор планеты через верхнее меню запускает стандартный автопилот. В момент достижения `arrival_radius` планета с `landing=landing` открывает привычный экран посадки автоматически. Ручной полёт, станции и орбитальные цели не изменены.
4. **Кристаллы:** удалён таймер `_mineral_spawn_timer` и функция `_spawn_mineral_cluster()` — кристаллы больше не возникают рядом с кораблём самостоятельно. Коллизии астероидов вызывают `_shatter`, где `kind=asteroid_index` сохраняет цвет астероида. Серые осколки не дают топливо, красные/синие/фиолетовые сохраняют прежние значения топлива. Магнит не меняется.
5. **Расы:** Солнечная система — люди; Большое Магелланово облако — грибы; Малое Магелланово — фазовые; Барнард/NGC6822 — рептилии; Андромеда/M31 — магнитные; Треугольник/M33 — нейронные формы. Все 30 назначений в реестре обновлены. Ракс и профессор Элиас исключены.
6. **Нижний HUD:** кнопка «Симулятор» смещена влево, «Вылет» — вправо; динамическое число и кристалл остаются посередине. Программный дизайн и шесть языков v63 сохранены.

**Пример миссии** (добавлять по готовности): `"missions":{"mw_p01":{"enabled":true,"title":{"ru":"Исследование Земли","en":"Explore Earth"},"subtitle":{"ru":"Экспедиция"},"description":{"ru":"Найди три объекта."},"image":"res://planet_hub/cards/mw_p01_mission.png"}}`. При отсутствии записи или `enabled=false` карточка скрыта.

**Проверки:** ZIP integrity; точные Git blob SHA для шести изменённых скриптов/реестра; SHA-256 полезной нагрузки; резервная копия и откат; повторная установка; отказ при локальном конфликте; отклонение повреждённого архива. Выполнены синтетические локальные тесты: первичная установка PASS, повторная PASS, конфликт PASS, повреждённый ZIP PASS. Запуск Godot 4.7.1 F5 в сборочной среде не выполнялся.

Mac-установщик попытается опубликовать полный установленный проект в `release/v64-installed-snapshot`, если доступен GitHub/git-lfs.
