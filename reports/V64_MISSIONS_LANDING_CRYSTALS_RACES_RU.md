# InfiniteSpace v64 — миссии, жесты, автопосадка, кристаллы, расы

## База

Патч устанавливается поверх `release/v63-installed-snapshot`; остальные игровые подсистемы сохраняются.

## 1. Скроллинг без ползунка

В `planet_hub/scripts/planet_hub_overlay.gd` и `scripts/NavigationMenu.gd` используется `ScrollContainer.SCROLL_MODE_SHOW_NEVER`: прокрутка сохраняется, сам ползунок не рисуется. Нативные touch-жесты сохранены; на компьютере добавлена прокрутка перетаскиванием мышью.

## 2. База заданий

`planet_hub/data/missions.json` содержит `missions` — словарь по ID планет и станций. **База пустая:** ни одной карточки миссии до явного добавления нет. Показ требует `enabled: true`; других автоматических заданий/описаний из атласа не создаётся. Пример будущей записи:

```json
{
  "schema_version": 1,
  "missions": {
    "mw_p01": {
      "enabled": true,
      "title": {"ru": "Исследование Земли", "en": "Explore Earth"},
      "subtitle": {"ru": "Экспедиция", "en": "Expedition"},
      "description": {"ru": "Найди три объекта.", "en": "Find three objects."},
      "image": "res://planet_hub/cards/mw_p01_mission.png"
    }
  }
}
```

При удалении записи или `enabled: false` карточка исчезает. Если нет миссии и нет представителя, отображается только фон и нижний HUD.

## 3. Автопосадка

Из верхнего меню выбор планеты по-прежнему запускает автопилот. По достижении `arrival_radius`, перед очисткой выбранной цели сохраняется её ID и проверяется запись в действующем атласе. Если `landing == "landing"`, автоматически начинается стандартная посадка/экран планеты. Орбитальные планеты, станции, ручной полёт и кнопка отмены маршрута не изменяются.

## 4. Цветные кристаллы

Полностью отключена функция `_spawn_mineral_cluster`, её таймер и вызовы. Кристаллы появляются только при `_shatter`, запущенном фактическими проверками столкновений. Прежняя модель сохраняет `"kind": asteroid_index`, поэтому красный астероид оставляет красные осколки, синий — синие, фиолетовый — фиолетовые, серый — серые (не дающие топливо). Сбор магнитом и ограничения на количество осколков не меняются.

## 5. Живущие расы — исправление

- `mw`: люди (Солнечная система)
- `lmc`: грибные/плесневые формы (Большое Магелланово облако)
- `smc`: фазовые формы (Малое Магелланово облако)
- `ngc6822`: рептилии (галактика Барнарда)
- `m31`: магнитные существа (Андромеда)
- `m33`: нейронные существа (Треугольник)

Все 30 существующих назначений в `representatives.json` перераспределены, исключённые `03_reptile_raks` и `04_human_professor_elias_braun` не назначены. Названия персонажей в карточках не возвращаются; описание планеты/станции сохраняется.

## 6. Нижний HUD

Прежний программный дизайн сохранён (дальнейшую художественную доработку пользователь отложил). «Симулятор» прижат к левому краю, «Вылет» — к правому, центральный кристалл и число остаются посередине. Шесть переводов действуют из `MobileLocale` как в v63.

## Проверки и ограничения

Проверка целостности архива, строгие Git blob SHA исходных 6 файлов, проверка хешей полезной нагрузки, поблочная резервная копия и откат, безопасная повторная установка. Программные тесты имитировали первую установку, повторную установку, конфликт локальных правок и порчу ZIP. Godot F5 здесь не запускается, визуальная проверка требуется на Mac.
