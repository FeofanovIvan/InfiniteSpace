# InfiniteSpace v61 — нижняя панель планет из оригинального PNG

База: `release/v60_1_1-installed-snapshot`.

## Реализация

- `planet_hub/assets/planet_bottom_panel.png`: **неизменённый** авторский оригинал (2048 × 684, RGBA с прозрачным фоном). SHA-256 проверяется при установке.
- `planet_hub/scripts/bottom_hud.gd`: в `_draw()` рисуется только оригинальная PNG-текстура без изменения пропорций. Фактическая видимая полоса изображения расположена примерно на исходных y=290…392, что учитывается при привязке к нижней границе.
- **Весь HUD масштабируется пропорционально высоте экрана** (`HUD_HEIGHT = screen_height × 158/864`) без верхнего ограничения, в том числе центр, кристалл, текст и кнопки. Точка x=1024 всегда совпадает с центром экрана. Стороны изображения могут выходить за края окна по X — это намеренно.
- Крупное белое динамическое число в центре (`CrystalCount`), подлинный `res://asteroid_assets/fragments/04_blue/crystal_wedge.png` с отдельным `TextureRect`.
- Старые программно нарисованные шасси, рамка и кристалл убраны, чтобы не скрывать исходную текстуру.
- Имеющиеся кнопки «Симулятор» / «Вылет», их значки и сигналы сохранены как временные активные элементы **поверх** панели; их отдельный визуальный дизайн — следующий этап.
- `planet_hub_overlay.gd`: высота панели равна `158 × screen_height/864` без ограничивающего максимума и не уменьшается из-за ширины 16:9/21:9. Планетные карточки отступают выше полосы, чтобы не пересекаться с ней.
- Источник счётчика (`show_for_planet(..., crystals)`) не изменён; никакие значения не подменяются примерным 509.

Скрипт обновляет только два UI-файла, добавляет PNG и независимую проверку; `Main.gd`, игра, диалоги, топливо, Play Town, сюжет и перелёты не затрагиваются.

Установка: `~/Projects/InfiniteSpace/InfiniteSpace_Godot`, резервные копии только заменяемых файлов, защита SHA-256, атомарная запись/rollback, повторная установка, GitHub snapshot, запуск Godot 4.7.1.

Проверено статически, геометрия оригинального PNG и работа установщика на опубликованных исходниках. Проверка Godot F5 на Mac остаётся обязательной.
