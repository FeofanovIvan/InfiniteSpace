# MIKA — Magnetic Collector / Магнитный сборщик (V1)

**Вселенная:** Андромеда, жидкометаллическая магнитная раса.  
**Движок:** Godot 4.7.1.  
**Формат:** самостоятельный запускаемый прототип, пригодный для дальнейшего переноса в InfiniteSpace.  
**Языки:** `ru`, `en`, `pt`, `es`, `de`, `fr` (так же, как в Safe City Kids / MIKA).

## Задача ребёнка

Подвесной электромагнит на верхнем рельсе собирает железные и стальные детали. Нужно **подвести магнит в нужное место**, **опустить** его к детали, **захватить** и **перенести в приёмный отсек слева**, затем нажать **ОТПУСТИТЬ**. Только доставленная деталь считается собранной.

- Левый джойстик: передвижение крана **влево/вправо**.
- Правый джойстик: **вверх/вниз** (длина троса).
- Большая кнопка внизу: **включить магнит / отпустить деталь**.
- Дополнительно: `A/D` или стрелки ←/→, `W/S` или ↑/↓, **Пробел**; `H` подсказка, `P` пауза, `R` рестарт.
- Поддержка **двух одновременных касаний**: можно одновременно двигать оба джойстика. Кнопка захвата работает отдельным нажатием.

## Уровни

1. **Основы** — 4 магнитных предмета, без лишних объектов.
2. **Проверка материалов** — 5 магнитных предметов плюс 2 немагнитных.
3. **Мастер магнитов** — 6 магнитных предметов плюс 3 немагнитных.

Металлические детали: шестерня, болт, железный шар, стальной брусок, шайба, винт. Немагнитные: камень, деревянный брусок, стеклянная бутылочка. Предметы выбираются и раскладываются случайно при новой игре.

**Очки:** +10 за успешно доставленную деталь, +20 за пройденный уровень. Максимальный результат за три уровня — **210 очков**. Ошибочные попытки не вычитают очки и не блокируют дальнейшую игру. Таймера нет.

## Стиль и ресурсы

- Глубокий тёмно-синий фон, светящиеся голубые грани, бирюзовые подсветки, округлые панели — визуальный язык остальных мини-игр MIKA.
- Магнит, трос, рельс, металлы, неметаллические объекты, частицы и виртуальные джойстики создаются **средствами Godot**.
- Файл `assets/star_core.png` взят из уже имеющихся ресурсов InfiniteSpace и используется как мягкий декоративный огонёк; других внешних изображений проект не требует.

## Запуск на Mac

Скопируйте ZIP в папку «Загрузки» и выполните:

```bash
cd ~/Downloads
unzip -o MIKA_Magnetic_Collector_Godot_v1.zip
bash MIKA_Magnetic_Collector_Godot_v1/OPEN_ON_MAC.command
```

В Godot нажмите **F5**. Для запуска игры без редактора можно использовать `RUN_GAME.command`.

## Как встроить в InfiniteSpace

1. Скопируйте `scenes/MagneticCollector.tscn`, `scripts/MagneticCollector.gd`, `data/strings.json` (лучше дать префикс, чтобы избежать конфликтов с другими играми), `assets/star_core.png` или замените ссылку на существующий ресурс звезды.
2. Сохраните структуру путей `res://scenes/`, `res://scripts/`, `res://data/`, `res://assets/` либо обновите пути в скрипте и сцене.
3. Сцена автоматически ищет `/root/LanguageService`; если он есть, использует `interface_locale` для элементов интерфейса и `learning_locale` для игровой локализации. При наличии `set_learning_locale` переключатель меняет язык обучения. Без него выбор хранится в `user://mika_magnetic_collector.cfg`.
4. При желании добавьте переход к сцене через общий каталог игр, а кнопку выхода — через основной Planet Hub.

## Что проверить на устройстве

Проверить одновременно два джойстика на сенсорном экране, комфортность скорости крана, расстояние магнитного захвата, разборчивость подписей на шести языках и попадание в приёмный отсек. Движок Godot **не установлен в рабочей среде создания архива**, поэтому проведена только статическая проверка проекта; запуск и мобильные касания потребуют проверки в Godot 4.7.1.
