# MIKA Gravity Pinball — V1

Технический прототип игры **«Гравитационный пинбол»** для Андромеды.

## Что реализовано
- запуск астероида из стартового кольца;
- выбор **направления** и **силы** запуском перетаскивания;
- гравитация от 4 планет;
- отскоки от планет и границ поля;
- мини-карта справа сверху;
- контрольные кольца / чекпоинты;
- счёт за время, пролёты и столкновения;
- 6 языков: `ru`, `en`, `pt`, `es`, `de`, `fr`.

## Важная пометка для замены ассетов
Сейчас весь визуал — **программный шаблон**. Для интеграции в проект нужно заменить:

1. **Фон космоса** → использовать фон из InfiniteSpace.
2. **Планеты** → использовать реальные мини-версии планет/объектов проекта.
3. **Астероид** → заменить на астероиды из проекта.
4. **Мини-карта** → можно использовать центр Солнца и ваши системные обозначения.
5. **Цвета интерфейса** → при желании привести к финальному стилю Андромеды.

## Идея запуска
Это не пушка, а **стартовое гравитационное кольцо / орбитальный ускоритель**.
Ребёнок тянет от кольца в обратную сторону — так задаёт направление и силу.

## Управление
- ЛКМ / палец: потянуть из стартового кольца и отпустить.
- RESET: начать новый запуск.
- Кнопки языка внизу.

## Запуск на Mac
```bash
cd ~/Downloads
unzip -o MIKA_Gravity_Pinball_Godot_v1.zip
bash MIKA_Gravity_Pinball_Godot_v1/OPEN_ON_MAC.command
```
