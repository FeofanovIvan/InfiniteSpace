# Алгоритм диалогов v98 — только логика, без изменения дизайна

Базовая ветка: `feature/v97-dialogue-stories-six-races`. Энциклопедия Перекрёстка миров, Planet Hub, портреты, панель выбора и клавиатура не меняются.

## Поток ответов

```text
greeting
  └─ корректное приветствие (любая из известных формулировок)
       └─ choose: общие темы
            ├─ self / race / origin / ability / energy / work / age / learn
            └─ world: история конкретной планеты или станции
                  └─ story: 3 вопроса по её истории
                        ├─ сюжетный выбор 0 ──┐
                        ├─ сюжетный выбор 1 ──┼─ story_adventure
                        └─ сюжетный выбор 2 ──┘    └─ 3 равноправных действия
                                                         ├─ исход 0 ─┐
                                                         ├─ исход 1 ─┼─ сохранение выбора
                                                         └─ исход 2 ─┘     ├─ choose
                                                                             └─ story_quiz*
```

*Небольшой квиз v97 появляется после приключения, если ребёнок выбрал третью сюжетную ветку. Необязательный; его можно пропустить.*

Переходы в `choose` доступны и из `story` / `story_adventure`: достаточно напечатать другой известный вопрос. `skip` / «Пропустить» закрывает необязательное приключение. Неизвестная реплика или ошибка набора **не отнимает прогресс**.

## Две главы на каждую цивилизацию

| Раса | Первое приключение | Следующее приключение |
|---|---|---|
| Люди | Найти замолчавший маячок | Записать открытие в дневник |
| Разумная плесень | Найти тихую веточку сети | Помочь веточке исследовать мир |
| Фазовые существа | Помочь потерявшейся капле | Праздник изменяющихся форм |
| Разумные ящеры | Восстановить путь в архиве | Исследовать старинную запись |
| Магнитные существа | Помочь сфере пройти между кольцами | Создать форму из металла |
| Нейронные существа | Составить узор из огней | Узнать ритм и сравнить порталы |

Все 12 глав имеют **три разных допустимых решения**, у каждого свой короткий итог. Нет «плохого» выбора: это исследовательские истории, а не тест с наказаниями. Вопросы, варианты, последствия и память переведены на `ru, en, fr, de, es, pt_BR`.

## Что персонаж помнит

Прогресс сохраняется локально в уже существующем `user://miko_dialogue_progress.json`:

```json
{
  "character_adventures": {
    "05_human_amara_cole.png": {
      "completed": 2,
      "last_episode": 1,
      "last_choice": 2,
      "last_place": "mw_p03",
      "history": [
        {"episode": 0, "choice": 1},
        {"episode": 1, "choice": 2}
      ]
    }
  }
}
```

Только технические индексы и ID. Не сохраняются произвольные фразы ребёнка. История ограничена последними восемью решениями. Тот же представитель на другой планете помнит разговор, а другой персонаж — нет. После двух глав они повторяются по кругу, сохраняя память о последнем выборе. Это ограничение текущей версии.

## Как распознаётся текст

- Выбранная из трёх реплик остаётся лишь подсказкой; правильные альтернативы признаются независимо от выбора.
- Существующий `dialogue_input_matcher.gd` продолжает игнорировать регистр, пунктуацию и случайные пробелы, исправлять небольшие ошибки набора.
- Если две формулировки одинаково похожи, алгоритм **не угадывает** смысл.
- Можно печатать известную фразу на любом из шести языков; интерфейс остаётся на языке игры.
- Неверная реплика не продвигает главу. Отдельный математический квиз продолжает проверять числа точно.

## Файлы

`planet_hub/scripts/dialogue_engine.gd` — новый этап `story_adventure`, обработка ответов, сохранение памяти, переходы к квизу или общим вопросам.

`planet_hub/data/dialogue_adventures.json` — 12 глав со вступлением, тремя решениями и тремя последствиями на шести языках.

`planet_hub/tests/dialogue_adventures_smoke.gd` — проверка прохождения всех рас и языков, повторных визитов и памяти между мирами.

## Проверка

```bash
godot --headless --path . --script res://planet_hub/tests/dialogue_smoke.gd
godot --headless --path . --script res://planet_hub/tests/dialogue_typing_tolerance_smoke.gd
godot --headless --path . --script res://planet_hub/tests/dialogue_stories_smoke.gd
godot --headless --path . --script res://planet_hub/tests/dialogue_adventures_smoke.gd
```

Тесты сохраняют первоначальный локальный файл прогресса, прежде чем запускать сценарии, и восстанавливают его после завершения. Версия Godot для CI фиксирована — **4.7.1**.
