# Write a Number — озвучка 11–20

Используется **один общий набор аудиозаписей** с игрой Pick Up a Number, без дублирования 60 файлов.

- Числа 1–10: существующие оригинальные записи.
- Числа 11–20: прежде всего `res://education/playtown/audio/voice/<язык>/numbers/number_XX.mp3`; если MP3 ещё нет — системный TTS по словарю `education/playtown/audio/voice/mika_number_tts_11_20.json`.
- Языки и каталоги: `ru`, `en`, `pt`, `es`, `fr`, `de`.
- 60 будущих MP3 (11–20 × 6 языков) перечислены в **уже существующих** `education/playtown/audio/VOICE_TODO_Pick_Number_11_20.csv` и `.md`.
- Можно добавлять файлы постепенно: конкретная запись MP3 автоматически заменяет TTS для **обеих** игр.
- Временные TTS-тексты не видны ребёнку. Предпочтение женским голосам по названию, если установлены в ОС; пол голоса нельзя гарантировать на всех устройствах.

Игра Write a Number произносит текущее число при выборе задания, при нажатии на изображение предмета и после завершения обводки.
