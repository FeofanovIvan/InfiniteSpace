# Infinite Space Godot Prototype v27 — rollback + map/integration fix

Сборка основана на **v25** (чтобы вернуть исходный HUD, управление, сборщик направлений и кнопку галактики),
и поверх неё добавлены только нужные изменения.

## Что сделано

1. **Возвращена логика v25 как базовая**
   - сохранены элементы управления;
   - сохранён destination picker;
   - сохранены кнопка галактики и кнопка меню;
   - сохранён старый игровой поток вместо «сломавшейся» первой сцены из v26.

2. **Интро заменено на присланное пользователем**
   - встроен модуль `mika_motion_comic`;
   - добавлен адаптер `scripts/ComicPrologue.gd`;
   - интро автоматически подстраивается под экран;
   - после интро остаётся переход к полёту и посадке на Землю.

3. **Карта галактик переделана**
   - убраны стрелки на линиях;
   - используются маленькие вращающиеся солнца;
   - центральный узел оставлен отдельным;
   - карта открывает 7 точек назначения.

4. **Переход между галактиками**
   - добавлен двухфазный гиперпрыжок;
   - корабль уходит к краю экрана/системы, затем появляется голубой туннель;
   - добавлен белый след;
   - выход из гиперпространства быстрый;
   - после прибытия обновляется текущая система и мини-карта.

5. **Системы atlas**
   - подключён `AtlasSystem.gd`;
   - подключены atlas-данные и planet preview assets;
   - destination picker теперь переключается под текущую систему.

6. **SMC модуль подключён**
   - добавлена папка `smc_planets/` из присланного архива;
   - `OtherSystem.gd` умеет использовать реальные SMC planet scenes.

## Что проверить в Godot после открытия

1. Открывается ли интро полностью и без чёрных полей на целевом экране.
2. После интро: корректно ли корабль идёт прямо к Земле.
3. Кнопка галактики:
   - карта открывается;
   - стрелок нет;
   - солнца маленькие и вращаются.
4. При выборе другой галактики:
   - HUD скрывается на время перехода;
   - корабль уходит в гиперпространство;
   - после выхода появляется новая система.
5. В SMC: отображаются ли реальные планеты из нового модуля.
