# Планетарные станции MIKO V1

Исходный архив: `MIKO_ORBITAL_STATIONS_V1_GODOT(1).zip`, предоставлен пользователем.
Оригинальные варианты 01, 02, 03, 04 перенесены в `station_overlays/scenes/`. Изображения back/front уменьшены до 512×512 с прозрачностью для экономии видеопамяти. Исходные 1024×1024 остаются в пользовательском наборе.

| Планета | Оформление |
|--|--|
| Земля | 01 экваториальное кольцо |
| Венера | 02 полярная дуга |
| Марс | 03 сеть причалов |
| Юпитер | 04 двойное кольцо |
| Нептун | 02 полярная дуга |

Станция на орбите Земли из `Miko_Station_Full_NEW` остаётся **отдельным объектом и целью**.

Каждый слой станции находится внутри Node2D, являющегося соседним узлом, а не потомком вращающегося глобуса; поэтому планета продолжает своё вращение шейдером, а инфраструктура остаётся фиксированной по ориентации. Позиция станции берётся от рассчитанного мирового положения планеты на каждом кадре. Реальные условия обитаемости планет здесь не моделируются.
