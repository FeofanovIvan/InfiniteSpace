# MIKA — реальный запуск сюжетной сцены первой главы

Эта ветка запускает **сам Godot**, а не веб-превью v14.6.2. На экране запускается основная сцена `res://scenes/main.tscn`, и сюжет первой главы начинается автоматически **без F8**.

## Запуск в отдельной рабочей папке на Mac

```bash
STORY="$HOME/Projects/InfiniteSpace/InfiniteSpace_Story_20261118"
git -C "$STORY" pull --ff-only
bash "$STORY/RUN_STORY.command"
```

Либо открой `project.godot` из этой папки в Godot 4.7.1 и нажми F5.
Если приложение Godot лежит не в стандартной папке, укажи его исполняемый файл переменной `GODOT_BIN`.

## Что проверяем в живой игре

1. При запуске начинается сохранённая анимация первой страницы `1-1.pdf`.
2. Появляется первый кадр `1-2.pdf` с червоточиной — касание/клик продолжает.
3. Видим реальный вылет корабля, вращение, подлёт и остановку возле Земли.
4. Видим два кадра Мики: планета Земля, затем симулятор. Каждый кадр листаем касанием.
5. В игре появляется существующая карточка симулятора; нужно нажать её.
6. Открывается реальный список игр. Можно войти в мини-игру, выйти к списку, но посадка ещё не начинается.
7. Только выход из самого списка игр запускает анимацию посадки.
8. Два заключительных кадра `1-2.pdf` показываются по касанию; после последнего касания открывается существующий экран Земли.

Верхняя кнопка `»` пропускает сюжет и возвращает к Free World. Автостарт относится только к этой отдельной ветке и не распространяется на основную сборку или сайт.

Если появляются ошибки, пришли вывод окна Terminal или текст из **Debugger → Errors**. Сейчас подтверждён кодовый маршрут и источник ассетов; запуск на твоём Mac после обновления ещё необходимо проверить.
