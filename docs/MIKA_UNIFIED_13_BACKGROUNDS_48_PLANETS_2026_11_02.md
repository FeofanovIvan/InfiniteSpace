# МИКА — единая схема 13 природных фонов для 48 планет и шести станций

**Дата:** 02.11.2026
**Назначение:** готовое техническое задание архитектору Godot для переиспользования ресурсов без дублирования PNG.
**Статус:** проект привязок, не применённый в Godot. Сюжет, расы, обитаемость и физические типы планет не изменены.

## Архитектурное решение

```text
Пустые(1).zip : 1.png ... 13.png
          ↓ ОДНОКРАТНЫЙ ИМПОРТ 13 PNG
res://assets/backgrounds/shared/empty_01.png ... empty_13.png
          ↓ ResourceLoader / один Texture2D на каждый ID
manifest[planet_id] → background_resource → фон планеты
                                     ├── необитаемая: отдельно только реликвии / робот / зонд
                                     └── обитаемая: отдельно станция/город нужной расы

12 прежних обитаемых планет MW/LMC/SMC → собственный согласованный PNG (не заменять)
6 обязательных станций st_* → шесть самостоятельных интерьерных сцен/фонов
```

**Итого:** 48 планет = **24 необитаемые + 24 обитаемые**. Из 24 обитаемых **12 уже имеют свои PNG**, остальные 12 используют общие природные фоны плюс станционные/жилые слои. Значит, **36 планет используют только 13 общих изображений**. Фоны не надо клонировать под разные IDs.

**Машинная карта для Godot:** [`MIKA_UNIFIED_13_BACKGROUNDS_48_PLANETS_2026_11_02.json`](MIKA_UNIFIED_13_BACKGROUNDS_48_PLANETS_2026_11_02.json). Все конкретные названия и ссылки ниже взяты из неё.

## Правила интеграции Godot

1. **Файл `Пустые/1.png` — только один раз:** импортировать как `empty_01.png` в общий каталог. Для двух/нескольких планет использовать **тот же** `res://.../empty_01.png`, а не копии.
2. **Никакой подмены расы или обитаемости:** использовать `settled`, `inhabitants`, `landing`, `unique` и статус станций из действующего `atlas/world_atlas.json`. Это техническая карта вида и оформления, не изменение игрового сюжета.
3. **Разделить природный фон и архитектуру:** для 12 новых обитаемых планет (Барнард 5, Андромеда 3, Треугольник 4) добавлять станции и архитектуру расы как прозрачные PNG/узлы поверх общего фона.
4. **Сохранить предыдущие 12 обитаемых PNG без стилизации и без дублирования видимых строений:** Солнечная система 5, Большое Магелланово Облако 3, Малое Магелланово Облако 4.
5. **Необитаемые миры не равны отсутствию объектов:** можно размещать существующие по атласу заброшенные руины, автоматические зонды и станции на орбите; не создавать действующих городов без сюжетного решения.
6. **Газовые гиганты:** фон — атмосфера/орбитальный вид, не твёрдая посадочная поверхность. Все места посадки и прогулки строго сверить с `landing`.
7. **Станции `st_*` не являются фоном для всех планет:** это отдельные обязательные локации; «Голова Титана» не должна автоматически отображаться на всех планетах Барнарда.
8. **Масштабирование:** landscape, заполнение всего экрана без чёрных полос; объекты и интерактивные кнопки должны находиться в адаптивной безопасной области. Не рисовать поверх PNG во время импорта.
9. **Файлы пока не присутствуют по предложенным путям:** каталог `res://assets/backgrounds/shared/` и имена `empty_*.png` указаны **как план внедрения**. Перед запуском архитектор импортирует реальные 13 PNG, после чего проверяет `ResourceLoader.exists` на каждом пути.
10. **По этой задаче изменений в Godot нет:** таблица передаётся архитектору, и только он подключает ресурсы/слои после проверки. Текущее содержание `atlas/world_atlas.json` менять не надо, кроме уже сделанного точечного уточнения `st_ngc6822.interior_view`.

## План приёмки

- Проверьте **48 уникальных ID планет**, а также **6 ID станций**.
- Из 48: 24 `settled=true`, 24 `settled=false`.
- Проверьте **ровно 13 уникальных общих PNG**, на которые ссылаются **36 планет**, и **12 индивидуальных** PNG первых трёх систем.
- Проверьте 12 отдельных поселений для новых обитаемых планет — без смены официальных рас.
- Проверьте 24 необитаемых мира: нигде не появляется действующая станция с жильцами только из-за наличия «руин» или «автоматического зонда».
- Проверьте четыре готовые иллюстрации станций и две незавершённые, а также что новые 13 ресурсов не заменяют изображения станций.
- В спорных случаях (Дуна, Руна, Мицела, Цикла, затмение Эклипсы) следуйте `note` в JSON и не объявляйте похожий фон физически точным.
