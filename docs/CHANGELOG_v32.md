# Infinite Space v32 — Orbital Rings for Inhabited Atlas Worlds

## Что сделано
- Подключены полноценные пакеты планет **M31** и **M33** (8 сцен в каждой системе).
- Все внешние системы теперь используют собственные planet shader scenes, а не только статичные превью.
- Для обитаемых/сюжетных планет во внешних системах добавлена генерация **2–3 кольцевых орбитальных станций**.
- Варианты станций выбираются из 4 готовых MIKO orbital station overlays в псевдослучайном, но стабильном порядке для каждой планеты.
- Трафик **не включался**: задел подготовлен только для окружения планет станциями.

## Обитаемые миры с кольцами
- LMC: первые 3 сюжетные планеты.
- SMC: первые 3 сюжетные планеты.
- NGC 6822: первые 3 сюжетные планеты.
- M31: первые 3 сюжетные планеты.
- M33: первые 3 сюжетные планеты.

## Что не менялось
- HUD, интро, гиперпрыжок, логика посадки и трафик.
- Центральная станция системы и уникальные системные солнца.
