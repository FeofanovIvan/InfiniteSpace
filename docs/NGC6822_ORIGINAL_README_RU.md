# Мико · Galaxy 04 · NGC 6822 (галактика Барнарда)

Восемь отдельных **анимируемых** 2D-планет для Godot 4.3+, рассчитанных на GL Compatibility / Android.
Никакой замены файлов основной игры. Все планеты из атласа — авторская фантастика; реальны только NGC 6822 и общие геологические аналоги. Станции, луны и поселения в этой версии **не рисовали**.

## Быстрый запуск тестового проекта

1. Распакуйте архив `Miko_NGC6822_Full_Godot_V1.zip` в новую папку.
2. Godot 4.3+ → Import → выбрать `project.godot` в этой папке.
3. F5 → восемь вращающихся планет. На телефоне можно касаться планет.
4. 1–8: крупный просмотр, Esc/тап: каталог, Space: пауза, C: облака.
5. Нокта (`ngc6822_p03`) имеет **нулевую скорость демонстрационного вращения**: приливный захват, постоянная ориентация к своей звезде.

## Перенос в существующий проект Мико

1. Распакуйте `Miko_NGC6822_Module_V1.zip`.
2. Скопируйте только папку `ngc6822_planets/` **в корень** текущего Godot-проекта.
3. В любой существующей сцене добавьте экземпляр `res://ngc6822_planets/planets/ngc6822_p01.tscn` (p01…p08).
4. Настройте `diameter_pixels` на самом узле (обычно 90–220 для свободного полёта; галерея 180px, при приближении 480px).
5. По желанию вызовите методы экземпляра: `set_planet("ngc6822_p07")`, `set_diameter(260.0)`, `set_spin_seconds(45.0)`, `set_sunlight(Vector3(-0.4, 0.2, 0.9))`, `set_clouds_visible(false)`.
6. Файл `project.godot` из тестового проекта в основной проект **не переносите**. Архивы прежних галактик не изменены.

## Структура

- `ngc6822_planets/catalog.json` — 8 ID, название, тип, параметры рендеринга, родительские звёзды (разные звёздные системы), выбранные спутники *только метаданные*.
- `ngc6822_planets/planets/*.tscn` — 8 отдельных сцен.
- `ngc6822_planets/planet_2d.tscn` — общая сцена.
- `ngc6822_planets/ngc6822_planet.gd` — поворот, облака, освещение, масштаб.
- `ngc6822_planets/planet_globe.gdshader` — сферическая текстурная проекция, дневная/ночная сторона, свечение горизонта.
- `ngc6822_planets/textures/` — 1536×768 JPG поверхности, отдельные 1536×768 PNG облака, белая 512×512 основа Sprite2D.
- `qa/sprites/` — 8 справочных прозрачных PNG по 640×640 (статичные, без анимации).
- `qa/ngc6822_story_rotation_preview.gif` — предварительная CPU-анимация **не запись Godot**.
- `tools/generate_ngc6822.py` — скрипт воспроизводимого создания текстур; Python3, `numpy`, `Pillow`, `scipy`, `opencv-python`.

## Важное о визуальной модели

Этот релиз именно **2D-фабрика**: сферичность имитируется GLSL-подобным шейдером Godot (`canvas_item`), который переносит 2:1 карту на видимую полусферу. Для детской игры не требуется тяжёлая 3D-модель. Красивый рельеф здесь изображён **цветом и тенями на текстуре**, а не геометрией реальных гор. Более крупные облеты можно позднее улучшить картами высот и нормалей, не меняя каталог ID.

Для `ngc6822_p03` Нокты световое направление в первом просмотре установлено отдельно, чтобы отчётливо показать постоянный сумеречный рубеж. При облетах в игре подавайте в `set_sunlight` реальное направление родительской звезды, не меняя значение осевой ориентации произвольно.

## Проверки

Проверены: восемь сцен и профилей, пути ресурсов, разрешения текстур, PNG с альфа-каналом, валидность JSON, воспроизводимость seed, CRC всех ZIP-архивов. **Запуск Godot в данной рабочей среде не выполнен** — нужно проверить F5 и затем Android на своей машине; результаты не называем испытанными в движке.
