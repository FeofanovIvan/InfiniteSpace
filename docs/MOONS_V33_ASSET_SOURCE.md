# Источник готовых 64 лун
- Предоставленный пользователем файл: `Miko_Moons_64_Full_NEW(1).zip`.
- Библиотека: `moon2d/`. Авторские текстуры из архива, не фотографии космических аппаратов.
- Каталог `moon2d/catalog.json` — окончательная привязка (`id`, `parent_id`, `galaxy`) и параметры вращения.
- При последующем редактировании не копировать один `moon_surface.png` на все луны.
- Лицензионные условия из исходного комплекта сохранены в исходном архиве. Игровая сборка использует пользовательские материалы без самостоятельной перепаковки в другие сцены, кроме индексирования и масштабирования.
