# V24 — полное оригинальное вступление и реальный облёт Солнца

* 7 исходных картинок скопированы без пересохранения и нарезки. Полный кадр помещается целиком в окно через CONTAIN с приглушённой размытой подложкой для полей.
* 250-градусная эллиптическая дуга вокруг Солнца (ось 430×310, перицентр 310 игровых единиц против диаметра Солнца 186).
* Непрерывная скорость, общие касательные на входе/выходе, рыскания носом и начальная раскрутка после чёрной дыры.
* Во время солнечного облёта камера удерживает Солнце в поле зрения и показывает движение корабля вокруг него.
* Выход по касательной, падающая траектория к движущейся Земле, масштабирование корабля, кратковременный дым, возврат управления.
* Трафик, редкие астероиды, мини-карта и 8 планет без изменений.
* Отладочная клавиша F8 повторно запускает ролик; Esc или » пропускает.
* Проверить Godot командой tools/verify_project.command и python3 tools/check_v24.py.
