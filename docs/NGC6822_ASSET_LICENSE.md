# Источники и лицензии

- Планеты NGC 6822 являются авторскими вымышленными мирами по файлу пользователя `MIKA_WORLD_ATLAS_V1.md`.
- Все восемь поверхностей и облачные маски созданы программно в этом комплекте из математического шума и авторских цветовых палитр. **В наборе нет изображений NASA, Hubble или Solar System Scope**.
- Все демонстрационные PNG созданы из тех же процедурных текстур.
- Фотографии конкретных настоящих экзопланет не подразумеваются. В NGC 6822 индивидуальные планеты из каталога не обнаружены наблюдениями.
- Код и созданные текстуры предназначены для интеграции в игру Мико без дополнительных указаний авторства внешних изображений.
