## Бюджет 100–120 MB

Фактический анализ сжатых данных APK выполняется `tools/analyze_apk_size.py`. Крупнейшие категории текущей сборки:

- Android runtime (`libgodot` + C++): около `24.7 MiB`;
- весь PlayTown: около `43.8 MiB`, из них шестиязычная озвучка `11.8 MiB`;
- планетные мини-игры после исключения старой Neural Math: около `14.7 MiB`;
- фоны посадки: `8.5 MiB`;
- карточки игр: `6.7 MiB`;
- луны: `5.7 MiB`;
- сюжетные станции/корабли: `5.0 MiB`.

До `100–120 MB` с запасом под будущий сюжет нельзя безопасно дойти одним ухудшением качества текстур. Рекомендуемая архитектура — оставить в базовой установке полёт, карту, планеты, пролог и сюжет, а PlayTown вынести в загружаемый PCK/Google Play Asset Pack. По текущему замеру release-база без PlayTown была бы около `103 MiB`, то есть оставляет примерно `17 MiB` до верхней границы `120 MiB` для первой главы сюжета. Дополнительно голосовые языки можно сделать отдельными пакетами.

Нельзя просто добавить `education/playtown/*` в `exclude_filter`: сначала нужен загрузчик пакета через `ProjectSettings.load_resource_pack()`, проверка версии/хэша и UI состояния «скачать/обновить».
