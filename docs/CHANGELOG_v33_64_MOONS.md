# Infinite Space v33 — подключение всех 64 лун

Дата: 2026-10-29. База: v32.1 (внешние кольцевые станции не менялись).

## Интегрировано

- Оригинальный пользовательский комплект `Miko_Moons_64_Full_NEW(1).zip`: `moon2d/catalog.json`, все 64 `moon2d/scenes/*.tscn`, все 64 индивидуальные поверхности `moon2d/textures/*_surface.jpg`, шейдер и reusable-скрипт.
- `scripts/MoonLibrary.gd`: статическое отображение `moon_id → PackedScene` с явными `preload` для всех 64 сцен и 64 JPG-текстур; устраняет риск отсутствия динамически загружаемых ассетов при экспорте.
- `scripts/SolarSystem.gd`: Луна Земли `mw_p01_m01` теперь из отдельной сцены, вместо единого серого спрайта.
- `scripts/AtlasSystem.gd`: ещё 19 лун Млечного Пути из индивидуальных сцен; орбиты и Каллисто как объект привязки верфи сохранены.
- `scripts/OtherSystem.gd`: 44 луны остальных 5 регионов из отдельных сцен, привязка к планете идёт по точным ID атласа, а не по совпадению названия.
- Используются нативная анимация вращения и собственные карты поверхности лун; освещение ориентировано приблизительно на центральную звезду. Спутники вне экрана скрываются для экономии отрисовки.

## Не менялось

- Контролы, корабли/NPC, интро, посадка, логика гиперпрыжка, маршруты движения планет, выбор галактик, кольцевые станции.
- Визуальные дубликаты станций и яркие маркеры из аудита — отдельный этап, здесь не затрагивались.

## Контроль качества

- `tools/check_v33.py` — проверяет совпадение **64/64** сцен, текстур, names/parent IDs/галактик/атласа; отсутствие старых общих спрайтов в 3 подсистемах и 64 explicit preload.
- `tools/check_v32.py` и `tools/check_v32_1.py` — обе пройдены.
- Важно: **реальный запуск Godot F5 и производительность Android не проверены**; проверка осуществляется на Mac после установки патча. Тестирование отличий визуальных моделей нужно провести на экране устройства.
