# Изменения единого глоссария «Мика»: 3.1 → 3.2

- `human_scientist`: утверждена манера речи — эксцентричная, короткая, неожиданная, не дидактическая и не непрерывно болтливая.
- Добавлен раздел 13.4.0: приключение и юмор отдельно от необязательного образовательного справочника.
- Учёный может сравнивать увиденное с земными аналогами (динозавры, нефть), не утверждая ложного тождества.
- Научные подробности готовятся для необязательной энциклопедии с проверяемыми источниками; реальные науки не заменяются фантастическими сюжетными допущениями.
- 48 планет, 6 станций, миры и основная сюжетная последовательность не изменены.
