# Прототип v0.2 — минимальный HUD и короткая остановка

- Удалены все экранные счётчики, подписи, подсказки, кнопки «Тормоз» и «Сброс».
- Джойстик перемещён в правый нижний угол.
- В левом нижнем углу добавлена аналогичная круглая кнопка действия с пиктограммой руки.
- Кнопка реагирует на мышь и мультитач; при нажатии emits `action_requested(mode)`.
- Предусмотрены будущие режимы use/take/talk/land, пока без выбора объектов.
- После отпускания джойстика/клавиш звёзды останавливаются плавно (~0.28 с или быстрее).
- Сохранены прежняя графика космоса, физика ускорения, трёхслойная система звёзд и корабль.
- Исправлена геометрия ввода джойстика при уменьшении размера контролов.
- Удалена неиспользуемая концепт-картинка из старого ZIP, чтобы не путать с игровыми объектами.
