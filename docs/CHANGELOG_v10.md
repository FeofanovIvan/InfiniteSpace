# Infinite Space v0.10 — MIKO V3 planets and Joystick parser fix

## Исправление запуска Godot
- `scripts/Joystick.gd`: строки `clear_input` и начала `_input` используют табуляцию, как весь остальной файл. Устранён отказ загрузить `Joystick.gd`.

## Полноценные сцены планет MIKO V3
- `res://planets/{mercury,venus,earth,mars,jupiter,saturn,uranus,neptune}.tscn` подключены через `SolarSystem.gd`.
- Использованы предоставленные шейдеры, исходные текстуры, слои облаков/атмосферы и два слоя колец Сатурна.
- Каждая планета имеет собственный период и направление вращения по игровым значениям из набора MIKO V3.
- Сохранены орбитальные позиции, размеры планет для детей, старт возле Земли, мини-карта и идентификаторы всех 9 целей автопилота.
- Освещение каждого мира направлено к Солнцу; положение обновляется при движении по орбитам.
- `PlanetPrototype.gd` больше не используется в проекте.

## Ограничения
- В приложенном наборе MIKO V3 7 текстур (кроме Земли) — *процедурные художественные варианты*, а не точные карты NASA. Скрипт установки официальных текстур из исходного пакета отдельно может подменить их, но для запуска здесь скачивание не требуется.
- Реальный запуск Godot на Mac/Android необходимо проверить. В архив включён скрипт статической проверки структуры.
- Лицензии/источники набора в `docs/MIKO_V3_CREDITS_AND_LICENSES.md`.
