# MIKA COMIC KIT · Godot 4.7.1 · v1.0

**Реализовано: 29 вариантов (12 `L`, 7 `P`, 10 `X`) с выбором по постоянным ID.** Это настоящий Godot-проект, не PNG-макет и не MP4.

## Как открыть

1. Распакуйте ZIP, откройте `project.godot` в Godot 4.7.1 (при наличии). Режим совместимости GL Compatibility; проект использует GDScript и `canvas_item` шейдеры без сторонних аддонов.
2. Нажмите **F5** — стартует каталог `CatalogDemo.tscn`: слева полный список `L01–L12`, `P01–P07`, `X01–X10`, справа интерактивный предпросмотр. Вверху смените имитируемые форматы 16:9, 21:9, 4:3, 20:9, 16:10. Для переходов используйте ползунок и ▶ PLAY. Для надписей ползунок показывает анимацию появления.
3. Нажмите **PAGE 01 · 71s INTRO**, чтобы увидеть исходную 71-секундную заставку с новой отрисовкой текста по `L##`. Управление: **Space** — пауза, **R** — сначала, **←/→** — на 5 секунд, **Esc** — в каталог. В проекте нет звуковых дорожек.
4. Для автоматической проверки синтаксиса и создания всех узлов запустите `godot --headless --path . --editor --import`, затем `godot --headless --path . --script res://mika_comic_kit/tests/smoke_test.gd`.

## Установка в основную игру

Для интеграции **не заменяйте `project.godot` вашей игры**. Из отдельного `MIKA_Comic_Kit_Integration_Module.zip` скопируйте папку `mika_comic_kit` в существующий `res://`.

- Каталог: `res://mika_comic_kit/demo/CatalogDemo.tscn`
- Заставка: `res://mika_comic_kit/page01/Page01LibraryDemo.tscn`
- Отдельная композиция: `res://mika_comic_kit/scenes/ComicStage.tscn`
- Отдельная надпись: `res://mika_comic_kit/scenes/ComicTextItem.tscn`
- Фабрика из одних только ID: `res://mika_comic_kit/scripts/comic_factory.gd`

**Пример использования в другом скрипте:**

```gdscript
const Factory = preload("res://mika_comic_kit/scripts/comic_factory.gd")

var card = Factory.make_text("L03", "The Crossroads of Worlds", Vector2(580, 145))
$CanvasLayer.add_child(card)
card.set_home(Vector2(50, 490))
card.seek_entrance(1.0)

var scene_panel = Factory.make_panel("P02", "city", "mica_balcony")
$ComicCanvas.add_child(scene_panel)
scene_panel.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)

var wipe = Factory.make_transition("X02", "city", "disaster_red")
$ComicCanvas.add_child(wipe)
wipe.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
Factory.seek_transition(wipe,"X02",0.6,"city","disaster_red")
```

Для смены типа плашки достаточно указать **другой ID**; все цвета, шрифты, геометрия берутся из реестра. `L03` — всегда фирменная фиолетовая плашка. ID заняты навсегда.

## Контракт стилей

- `L01` авторский caption, `L02` речь, `L03` фиолетовый блок, `L04` тревога, `L05` радио, `L06` шёпот, `L07` мысли, `L08` крик, `L09` SFX, `L10` заголовок, `L11` время/место, `L12` голос за кадром.
- `P01` полный экран, `P02` диагональный дуэт, `P03` новости, `P04` окно, `P05` три полосы, `P06` перекрывающиеся карточки, `P07` персонаж за рамкой.
- `X01` слайд, `X02` диагональный переход, `X03` разделение, `X04` приближение, `X05` match cut, `X06` круговая маска, `X07` выход персонажа, `X08` параллакс, `X09` ударная тряска, `X10` растворение.
- Шрифты `F01 Comic Neue Bold`, `F02 Nunito Sans Bold`, `F03 Bangers`, `F04 Nunito Sans Italic`. Палитра `C01–C12` соответствует предыдущему ТЗ.
- Изображения рендерятся в режиме **COVER** в любой горизонтальной пропорции, без чёрных полос. При несовпадении форматов края изображения **целенаправленно кадрируются**, но не растягиваются.
- Текст — отдельные узлы поверх изображения. При построении нового эпизода задавайте `protected_zones` для лиц, глаз и важных объектов. `ComicLayout.locate` ищет позицию с минимальными пересечениями. Если невозможно вместить длинную реплику, нужно разделить её или изменить расположение кадра.
- Эффект `P07`/`X07` **требует отдельного PNG персонажа с прозрачным фоном**. В каталоге прилагается минимальная демонстрационная силуэтная иллюстрация `cutout_demo_RGBA.png`. Реальную иллюстрацию Мики следует вырезать отдельно, не подменяя оригинал.
- Включайте `reduce_motion` у `ComicStage` для ограничения тряски; никаких звуков в проекте нет.

## Общие данные для PDF-журнала

`mika_comic_kit/data/comic_tokens.json` — цвета, размеры и шрифты. `comic_element_catalog.json` — все ID и их значения. `page01/page01_cues.json` — 14 английских реплик с таймкодами, `style_id` и защищёнными областями. `data/pdf_export_manifest_page01.json` — ссылка каждого диалога на печатный формат. Оригинальная A4-иллюстрация 300 dpi сохранена в `page01/MIKA_Comic_Page_01_A4_300dpi.png`.

**Для печати не делайте скриншоты Godot:** берите оригинальную графику и строите соответствующие векторные элементы с теми же ID в Scribus/Inkscape. Эффекты `X` в печатной версии превращаются в статичные композиции, не «видео в PDF».

## Шрифты, зависимости и статус проверки

Сторонние аддоны Godot не нужны. **Файлы шрифтов не входят в архив**; по умолчанию работает встроенный шрифт Godot. Для фирменного вида самостоятельно разместите правомерно загруженные `F01.ttf`, `F02.ttf`, `F03.ttf`, `F04.ttf` в `mika_comic_kit/fonts/` и соответствующие файлы лицензий. Получать их следует из официальных источников, как описано в JSON токенах.

Пакет статически проверяется поставляемым `QA_STATIC.py` и упакован без ссылок на другие проекты. **В этой среде нет исполняемого файла Godot, поэтому запуск движка и визуальная приёмка пока НЕ выполнялись**. Сцены с публичным API подготовлены, но потребуется импорт и тест на целевой версии 4.7.1. В случае ошибки приложите текст из Godot Debugger/Output, чтобы исправить конкретный скрипт.
