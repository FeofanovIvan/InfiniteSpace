# InfiniteSpace — UI audit baseline (2026-11-05)

**Scope:** read-only study of the uploaded local `InfiniteSpace_UI_Audit.zip`. This is a reference branch, not a game patch. The running Godot project and `main` are unchanged.

## Snapshot coverage
- Local project inventory: **9,250 files**; **254 .tscn scenes**; **313 .gd scripts**.
- The supplied audit archive included **1,007 project files**, comprising a selected subset of text assets and interface images; some backup folders are included.
- The audit archive is **not** a complete project clone or a clean source release. Avoid uploading it wholesale to the public repository.
- The local installed project contains newer patches than GitHub `main`; `main` is not the current UI authority.

## Source-confirmed style details
- Settings panel fill: `#061c38`; cyan outline: `#26dfff`; 2 px border and 24 px corner radius.
- Settings buttons derive styling from `_style()` and are positioned in `_layout()` using `MobileLocale.safe_rect(view)`.
- Simulator back button: `#061c38`, `#26dfff` 2 px border, 18 px corners, shadow/glow; graphical arrow comes from `BackArrowGlyph`.
- Simulator background uses the same shader-based deep-space rendering as flight.
- Planet cards use `res://planet_hub/scripts/planet_card.gd`; their default physical design is based on 430×540 and scales with the viewport.
- Navigation uses Godot Controls, responsive geometry, touch input and scroll containers, rather than a stack of arbitrary overlays.

## Constraints for upcoming design
1. Do **not** continue patching the old encyclopedia UI. Keep only JSON data and its translations.
2. Reuse actual native UI pieces after comparing game, simulator, planet hub and settings styling.
3. Work on one visual element at a time after the user's direction.
4. Do not commit backups, cache, APK/IDs, configuration with credentials, or broad downloaded game assets into the public repository.
5. Do not claim the full UI audit is complete: code and scene inventory is verified, but the 34 game screens and responsive states still need a fuller systematic review.

## Notes about publication
