- Последний патч v45 называется `InfiniteSpace_v45_Patch_SMC_NativeFleet_Triangulum_LastGate.zip`. Флот пяти классов находится в SMC, «Последние врата» — M33. Релиз имеет локальные зависимости на более ранние патчи.

## Обязательное правило
1. При каждой доработке проверять рабочую версию и GitHub commit.
2. При изменении кода/ресурсов включать их в commit GitHub и записывать идентификатор SHA в отчёте релиза.
3. Если сеть, права доступа или передача бинарных ресурсов не позволили создать полный commit, **явно помечать релиз как не синхронизированный**, не говорить «загружено в GitHub».
4. Не перезаписывать main старой версией ZIP и не выдавать частичный commit за полную игровую сборку.
5. Для релиза предусмотреть автоматическую проверку наличия файлов и зависимостей, Godot headless parse и проверку движения в Godot.
6. Не запрашивать у пользователя файлы, которые уже есть в GitHub или ранее приложенных архивах, без подтверждения реальной недоступности.
