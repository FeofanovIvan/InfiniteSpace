# InfiniteSpace — правила свободного мира, Перекрёсток и планетарные игры (v103 / проектные пометки)

**Статус:** согласованная структура + черновой реестр данных. **Не является готовой игровой интеграцией.** Создано по обсуждению от 03.11.2026. Главные игровые скрипты, меню, посадка, существующие карточки и сохранения не изменяются.

## 1. Свободный мир и сюжет

- Режим по умолчанию — **Свободный мир**. Игрок может выбирать его сразу, не проходя сюжет. Продолжаем разработку именно этого режима.
- **Сюжет** — отдельная последовательная ветка, которая позднее будет содержать миссии, задания и ролики. Существующую главную сюжетную заставку закрепить только за выбором «Сюжет».
- В меню / настройках предусмотрен выбор «Свободный мир» / «Сюжет». **Пока сюжетный пункт можно скрыть или оставить неактивным**; не удалять ресурсы заставки.
- **Сохранения — отдельный будущий этап**: текущая система, планета/станция, положение корабля, топливо/кристаллы и награды, открытые миры, прогресс заданий, прохождение сюжета, доступ к Перекрёстку, питомец. Данные должны переживать перезапуск приложения и следующую сессию.
- Это **не** означает немедленную замену экрана запуска или принудительный пропуск уже работающей заставки: нужна самостоятельная версия с тестированием.

## 2. Перекрёсток миров — Живая планета

- Перекрёсток открывается после завершения главного сюжета и **остаётся доступным** в дальнейших сессиях / свободном мире.
- К живой планете можно подлетать, но **посадку не предлагать**. Вблизи появляется действие **«Разговор»**; оно открывает диалог прямо из космоса.
- Компоновка диалога — слева **сама живая планета** как персонаж (без отдельного жителя), справа **существующий планшет-переводчик**, фон — **наш космос**, не поверхность.
- Использовать **именно** файл `planet_hub/data/crossroads_encyclopedia_v95_48_topics.json`, сохраняющий оригинальные 48 тем. 3 раздела × 16 тем: забота, наука, Вселенная.
- В JSON есть вопросы/ответы **RU и EN**. Для FR, DE, ES, PT-BR переведены главные вопросы и элементы интерфейса, **ответы не переведены**; до перевода явно поддерживать fallback, а не показывать полностью локализованную энциклопедию.
- **Открытый вопрос:** когда отдельный новый профиль выбирает свободный мир, **не проходя сюжет**, открывать ли ему Перекрёсток сразу? Пока не выдумывать ответ: после сюжетного прохождения доступ постоянен, для нового свободного профиля правило ещё требуется выбрать.
- Совместимость в JSON упоминает `planet_hub/scripts/crossroads_encyclopedia.gd` из v94, но этого файла в проверенной GitHub release-ветке **нет**. Поэтому одного JSON недостаточно для работающего диалога — движок и подключение будут отдельной задачей.

## 3. Планетарные мини-игры

- Каждая из **6 систем** имеет **4 разных игры**: всего **24 уникальные игры по плану**.
- На каждой **обитаемой планете** от **1 до 2** карточек / заданий; одна игра может повториться на другой планете той же системы. На станциях задания пока не назначаем.
- На каждой из **24 необитаемых планет** — **ровно одна общая игра**, прогулка с Бабблом. Никаких игр цивилизаций там не появляется. Правило открытия посадки и самого игрового окна нужно отдельно проверить в Godot, прежде чем вводить.
- Атлас `atlas/world_atlas.json` в проверенной ветке содержит **24 обитаемые + 24 необитаемые** планеты (станции не входят в эти числа).
- **Первый черновик распределения по точным ID** уже есть в `planet_hub/data/planetary_games_draft_v1.json`. Все 48 миров указаны; распределение 1–2 игры на обитаемый мир выполнено, но пока не утверждено.
- **Кодовое состояние:** 8 игр существуют в PlayTown как отдельные сцены и имеют точно проверенные пути: Пазлы, Среда обитания, Список покупок, Подсчёт предметов, Пицца и дроби, Закати шарик, Piano, Matching Pairs. Это **не** означает, что они уже доступны на планетах через карточки.
- Ещё 3 механики есть как кандидаты на адаптацию: Построй путь → Грибные пути; Color Mix → Лаборатория растворов (механика другая); Color Sort v102 → Яйца динозавров (эта сцена доступна через **локальный патч v102**, а не подтверждена в ветке GitHub).
- Остальные 13 мини-игр предстоит разработать / импортировать, проверить и оформить.
- `planet_hub/data/missions.json` в базовой проверенной ветке **пустой**. Текущий `PlanetHubOverlay` отображает только **одну** `MissionCard` и не имеет подтверждённого перехода в сцену планетарной игры по нажатию. Для 1–2 заданий нужен отдельный адаптер карточек и портала мини-игр; **не подменять без проверки действующий симулятор**.
- Список названий, сцены и текущие статусы по всем 24 играм находятся в файле реестра.

### Готовые к интеграции оригинальные PlayTown-сцены

| Система | Плановые игры и степень готовности |
| --- | --- |
| Млечный Путь | Пазлы ✅, Animal Habitat ✅, Shopping List ✅, Product Count ✅ |
| БМО (плесень) | Грибные пути 🛠 (есть Path Builder), солнечный луч ⏳, эко-сортировка ⏳, грибная гонка ⏳ |
| ММО (фазовые) | Молекула ⏳, растворы 🛠 (есть Color Mix), сбор ресурсов ⏳, ледяная планета ⏳ |
| Барнарда (ящеры) | Останки ⏳, эволюция ⏳, яйца 🛠 (локальный Color Sort), Pizza Fraction ✅ |
| Андромеда | Закати шарик ✅, магнитный сборщик ⏳, гравитационный пинбол ⏳, импульсы ⏳ |
| Треугольник | Piano ✅, Matching Pairs ✅, Space Rebus ⏳, нейронная математика ⏳ |

✅ — исходная сцена проверена в GitHub, ещё **не подключена к планете**. 🛠 — существует только базовая/похожая механика, требуется адаптация. ⏳ — новой игры в текущем каталоге нет.

### Технические файлы

- `data/free_world_design_v1.json` — режимы, сохранения, Перекрёсток.
- `planet_hub/data/planetary_games_draft_v1.json` — 24 игры, 48 планет, черновое распределение.
- `planet_hub/data/crossroads_encyclopedia_v95_48_topics.json` — исходная энциклопедия из пользовательского JSON, **48 тем**, без сокращений.

**Важно:** эта ветка создана от `release/v94-ten-simulator-cards-three-empty-scenes`, которая содержит подтверждённые исходники PlayTown, но **не отражает автоматически все последующие v95–v102 локальные ZIP-изменения на Mac**. Пока здесь только *новые* файлы данных и документация — к `Main.gd`, `MikoMainMenu.gd` и сценам игр патчи не применялись.
