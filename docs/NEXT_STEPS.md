# Дальнейшее развитие

Текущая версия — исключительно дальний звёздный фон, без игровых объектов.

1. Измерить FPS на Android и по необходимости уменьшить `STAR_COUNTS`/количество звёздных слоёв.
2. Добавить отдельный `NearWorld`, в котором будут планеты, орбиты, астероиды и игровые корабли. `NearWorld` не должен двигаться через фоновые правила; нужен отдельный масштаб/система координат.
3. Добавить опциональную далёкую космическую дымку шейдером на основе `FastNoiseLite` / fBm. Начать с 1-2 слабых слоёв — не затмевать точки.
4. Добавить тонкие пульсации отдельных ярких звёзд, сохраняя экономичную пакетную отрисовку.
5. Добавить плавный переход от физической игровой карты к чисто визуальному дальнему полёту, при котором корабль остаётся на экране, а физические координаты больше не растут.
6. Подключить параметры палитры и плотности к удобной игровой панели настройки.
