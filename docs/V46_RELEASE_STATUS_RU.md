Установщик `install_v46.py` накладывает v46 поверх v45, проверяет контрольные суммы, сохраняет резервные копии, изменяет `OtherSystem.gd`, `ForeignTraffic.gd`, `NpcTraffic.gd` и добавляет `LastGateFX.gd`, `ShipMotionFX.gd`.

**Важное ограничение:** GitHub `main` по-прежнему не содержит полного набора файлов v39–v45; часть исходников и бинарных ассетов есть только в локально установленной версии и ZIP-патчах. В GitHub пока *частичная* синхронизация v46, а не полная сборка.

## Восстановление единого источника истины
Скрипт `sync_v46_to_github.sh` включён в v46 ZIP. После установки на Mac он создаёт или обновляет ветку `release/v46-installed-snapshot` безопасным способом: клонирует GitHub в отдельный каталог, копирует актуальный рабочий Godot проект, не переносит кеши/бэкапы и пытается опубликовать ветку без изменения `main`. Успех зависит от доступа к GitHub и настроенной авторизации Git на Mac.

Следующий чат должен сначала проверить эту ветку. Только **подтверждённый SHA опубликованного полного snapshot** позволяет утверждать, что GitHub полностью догнал локальную игру.
