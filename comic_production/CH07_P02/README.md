# MIKA_CH07_P02_NEBULA_6LANG_v31

Глава 7, страница 2: шесть литературных локализаций RU, EN, PT-BR, ES, FR, DE.

Русская композиция основана на согласованном воздушном макете v2; в последней реплике v3 исправлена реальная ошибка переполнения: прежний текст 339 px при допустимых 289 px. В v31 финальная реплика полностью помещается в расширенном облачке с внутренними полями.

- 9 озвучиваемых Line ID, 11 видимых текстовых элементов.
- Два говорящих: Мика CHR_001 и новый голос зелёного облика живой планеты CHR_040.
- 54 локализованных клипа, 12 мастер-текстов TTS. Аудио не создавалось.
- Для L004 и L005 два визуальных элемента составляют одну фразу озвучки; все 6 языков имеют ту же структуру.
- Векторы SVG редактируемые, PNG прозрачные, контрольные PDF содержат оригинальное изображение. Изображения не генерировались и не редактировались.
- Накопительный JSON v30 расширен без изменения старых ID; Excel дополнен, включая недостающие исторические строки кастинга.
- Проверены текстовые размеры во всех 66 экранных блоках, данные JSON/Excel и SHA256.

Папки: `source`, `overlays`, `previews`, `metadata`, `registry`, `tts`, `godot`, `catalog_reference`.
