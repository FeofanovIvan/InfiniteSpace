* `CHR_038`: новый **закадровый голос нейронных существ** через телепатический симулятор. Это не мысль Мики и не авторский голос `CHR_004`. На иллюстрации — бирюзовые речевые облака NEBULA `speech_left/right` без привязки к изображённому существу. Не назначать ему голос автора.
