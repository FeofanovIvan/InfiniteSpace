# MIKA — семь областей звёздной карты (Godot 4.7.1)

Этот проект является продолжением Infinite Space v0.25. Ничего из Солнечной системы не удалено.

1. Запусти `project.godot`, F5, пропусти вступление.
2. Нажми круглую кнопку галактики справа и выбери одну из шести галактик или Перекрёсток миров.
3. После гиперпрыжка вернётся джойстик. Круглая панель планет показывает объекты текущего мира.
4. Вернись в Milky Way через ту же карту, чтобы проверить NPC, астероиды и планеты прошлого проекта.

Тест: `python3 tools/check_v26.py` — стандартный Python 3, без внешних библиотек.

Детальный реестр готового и недостающего: `docs/ATLAS_PROGRESS_V26.md`.
Источник: `atlas/world_atlas.json`, сформированный по твоему `MIKA_WORLD_ATLAS_V1(2).md`.
