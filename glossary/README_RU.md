# Глоссарий InfiniteSpace — Godot 4.7.1

Самостоятельная полноэкранная страница в корабельном меню (scripts/MikoMainMenu.gd).

## Навигация
1. Открыть корабельное меню штатной кнопкой в HUD.
2. В верхнем правом углу нажать **Глоссарий** / **Glossary**.
3. Выбрать раздел: планеты, станции, расы, персонажи, наука или технологии.
4. Прокручивать вертикальный список пальцем, колесом или трекпадом. В списке можно искать по названию и тексту.
5. Первая кнопка «назад» возвращает к категориям, вторая — в корабельное меню.

## Источники
- glossary/data/public_encyclopedia.json — короткие открытые описания природы, 24 сооружений, рас, станций и терминов.
- atlas/world_atlas.json — живой каталог 48 планет. Необитаемые: только природный фон, без декора.
- planet_hub/data/representative_profiles.json — 30 уникальных NPC с именем и фотографией-образцом. Используются только name, portrait_template и открытая характеристика; mystery/share/chapter_cues не читаются.
- planet_hub/data/crossroads_encyclopedia_v96_6_languages.json — 48 готовых детских научных тем на шести языках.
- Изображения планет, персонажей и станций используются из существующих папок Godot; если иллюстрации нет, текст остаётся видимым.

## Добавление материала
- Для планеты поменяйте planet_notes.<id>.description; для обитаемой — ещё building.
- Новый NPC подхватывается из representative_profiles.json автоматически. Для русского короткого занятия можно добавить запись в character_roles по world_id.
- Науку добавляйте в источник Перекрёстка; интерфейс читает его автоматически.
- Новые статьи о технологиях добавляйте в terms.
- Не записывайте в публичные статьи поля mystery, share, chapter_cues, сюжетные открытия, концовки и тайны происхождения.

## Проверка
Запустить в Godot 4.7.1:

    godot --headless --path . --script res://glossary/tests/glossary_smoke.gd

Текущий UI поддерживает русский основной текст и локализованные заголовки/ответы 48 научных статей из набора v96 (ru/en/fr/de/es/pt_BR). Остальные описания мира пока авторские русскоязычные; полную локализацию этих текстов нужно добавить отдельно. Визуальная проверка на Mac/iOS/Android ещё не выполнена.
