# Infinite Space v0.25 — полноэкранный кинопролог Мики

Этот архив содержит полный Godot-проект. Обновление выполнено на базе v0.24 с исправлениями v0.24.1 и v0.24.2.

## Вступление

В `assets/prologue_original/` лежат девять целых исходных PNG. Новые кадры: `04_city_under_vortex.png` и `05_storm_sweeps_city.png`.

Код `scripts/ComicPrologue.gd` отображает по одному исходнику на весь экран, без нарезки и без фонового изображения с полями. Камера панорамирует внутри текущего исходника и меняет масштаб. Для заполнения экрана при разном соотношении сторон видимая область неизбежно ограничена краями экрана, но сам файл не обрезается: во время движения камера показывает разные участки.

Короткие перекрытия (crossfade) обеспечивают переходы между сценами. На двух последних кадрах есть лёгкая тряска. `»` и Escape пропускают вступление; F8 повторяет его.

## Полёт

`Main.gd`: после вылета из чёрной дыры корабль непрерывно движется к Земле по одной кубической кривой Безье. Облёт Солнца и промежуточные остановки полностью удалены. Сначала корабль раскручивает, затем нос постепенно стабилизируется, а перед столкновением начинаются тряска и визуальное уменьшение. Земля остаётся движущейся целью. После удара показывается заметный полупрозрачный дым (`StoryLandingSmoke.gd`). После вступления игра возвращает управление.

## Проверка

```
python3 tools/check_v25.py
```

Для полноценной проверки шейдеров и анимации — запуск F5 в Godot 4.7.1 на Mac. Здесь выполняются статические проверки, а не тест фактического рендеринга.

Важно: обновление не удаляет предыдущие папки `assets/prologue/` из локально установленного проекта; они просто перестают использоваться. Папка `reports` сохраняется.
