# Слои персонажей для мостика Мико

Сюда можно поместить настоящие PNG персонажей (прозрачный фон):

- `miko.png` — оригинальный герой пользователя, подключён в v0.22 по центру
- `crew_left_1.png`, `crew_left_2.png` — два левых кресла
- `crew_right_1.png`, `crew_right_2.png` — два правых кресла

Экран `scripts/MikoMainMenu.gd` проверяет наличие изображений при запуске. Если файла нет, кресло остаётся свободным. Случайные заменители персонажей не используются. После добавления файлов перезапустите проект.
